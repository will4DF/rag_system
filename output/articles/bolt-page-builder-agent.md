Learn how to create and edit pages with the Bolt Page Builder Agent.

# Overview

The Bolt Page Builder Agent is a revolutionary way to create ready-to-publish pages in Element451.

* Use natural language in a conversation format to guide the agent in creating and refining your ready-to-publish page, complete with CTAs, teasers, text, pictures, and more!
* With the help of your Knowledge Hub, the agent can create a page complete with precise and relevant information tailored to your audience and goal.
* The agent uses Packs Content Tokens to create on-brand pages that look like your marketing department designed them.
* Want to build your own page? You can still use the agent to generate your headlines.

---

# Generate Complete Pages

The Bolt Page Builder Agent can create ready-to-publish pages. Describe the page you need, and it will generate an outline and preview based on your prompt. Learn how:

## Before Trying Bolt Page Builder Agent

One of the most important aspects of successful pages is personalization. That's why the agent utilizes your information from Element451, including **Content Tokens** like colors, logos, and the **Knowledge Hub**, to tailor your pages.

It's crucial to keep these elements updated to ensure optimal results. By staying on top of these details, the agent can create campaigns that truly resonate with your audience and achieve your desired outcomes.

1. Review your **Content Tokens** to ensure they are up-to-date.

   * To access Content Tokens: **Data** **+ Automations** **> Packs > Content Tokens**
   * For more information on Content Tokens, [click here](https://help.element451.com/en/articles/6825249-guide-to-packs-tokens).  
     ​
2. Add sources to the Knowledge Hub and review existing sources for accuracy and relevance.

   * To access the Knowledge Hub: **Data** **+ Automations** **> Knowledge**
   * For more information on building your **Knowledge Hub**, [click here](https://help.element451.com/en/articles/10302715-getting-started-with-knowledge-hub).

## Generate a Page Using Bolt Page Builder Agent

1. Navigate to **Engagement** > **Pages**
2. Click **+** **New** **Page** buttonin the top right corner
3. Name your new page and click **Save**
4. Click **Edit Page**
5. Click **Edit with Bolt AI**.
6. Use natural language to describe the page you need.
7. The Bolt AI side panel will open, where you can **provide information about the page you want created**. *Note: Bolt AI is conversational and designed to ask follow-up questions if it requires additional information.*
8. The agent will draft an **outline** of your page for you to review. Click on each angle bracket to expand the details.

   * If you want to make changes, reply with your change requests.
   * If you **approve**, tell the agent or click "**I like it. Continue.**"
9. The agent will then draft the **components** of your page for you to review. When it's done, it will say **all components created**.
10. Click the X to close the conversation with the agent and preview your page.
11. You can then manually edit the page or click edit with Bolt AI to ask the agent to make any changes.

# Generate Page Headlines

Bolt AI can generate a page headline using a description or a list of keywords separated by commas. Learn how:

1. When creating a page, type the description of the page using text or comma-separated keywords.
2. Highlight the text.
3. Select the **Generate Headline** icon.
4. The agent will then replace the original text with your newly generated headline.
