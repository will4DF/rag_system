Learn how to create requests for information and assign them to your applications.

# Overview

The **Request Information** feature within **Applications** allows students to easily request documents or information from third parties within an application (e.g., transcripts, fee waivers, test scores, letters of reference).

With just a few clicks, you can add an Information Request to your application(s). Upon application submission, the request automatically sends an email to the third-party/recipient.

This feature streamlines the application process by enabling students to request information and documents at the time of application.

### Referencing Applicant's Form Data in Recommender Form

You can display information from the applicant's form directly on the recommender form. This provides recommenders with additional context when completing their recommendation.

#### How It Works

Custom tokens can be used on Information Request Recommender Form elements (greeting and message sections only) to pull data that the applicant submitted in their form.

* To reference applicant data, use the following format:   
  ​**`[inforequest:field-slug]`**
* All custom tokens for applicant data must be enclosed in square brackets and use the prefix **`inforequest:`** followed by the field slug.

  + Example: If your applicant form contains a field that collects the student's Hogwarts house, you could include their answer on the recommender's form with this token: **`[inforequest:user-custom-training-hogwarts-house`]**. When the recommender views their form, they would see the actual Hogwarts house that the applicant selected (e.g., "Gryffindor").
* To find the correct field slug for the applicant form field, open the applicant's form and copy the slug from there.

1. Navigate to **Applications** > **Applications** > **All Applications.**
2. Select the application to which you wish to add the form.
3. From the left-hand side menu, click **Request Information** under*Content***.**  
   ​

   [![](https://downloads.intercomcdn.com/i/o/840574565/4b11c32e004e75c6dfb85a62/Screenshot+2023-09-27+at+4.21.50+PM.png?expires=1784333700&signature=63cc48d448fc74cb731370e584c8b72437e5bca5cadf5e1ab101ed2734d06590&req=fCQnE856mIdaFb4f3HP0gG4gD7so8t2eY3C9g5jcoC4corpmhZpWkfj%2FpzjE%0AoMI%3D%0A)](https://downloads.intercomcdn.com/i/o/840574565/4b11c32e004e75c6dfb85a62/Screenshot+2023-09-27+at+4.21.50+PM.png?expires=1784333700&signature=63cc48d448fc74cb731370e584c8b72437e5bca5cadf5e1ab101ed2734d06590&req=fCQnE856mIdaFb4f3HP0gG4gD7so8t2eY3C9g5jcoC4corpmhZpWkfj%2FpzjE%0AoMI%3D%0A)
4. Customize the **Request Information** section (Note: Because you have the ability to add multiple Requests for Information to a single application, this step **creates a section** within the application.):

   **Title and Description**: Explain this section to the student. Remember this is a section, and each Information Request will have its own description. Therefore, if you will require more than one request, keep it general. If you just have one request, like a transcript request, you can be more specific.

   ​**Add Request Type**: Select the request form from the dropdown that you created in the first step. You also have the ability to:

   * Add multiple information requests
   * Choose to make the request **optional** or **required**
   * Choose to **limit the number of requests**
   * Configure any **conditional logic** to segment the population that will see the request.

   ​**Sidebar Title and Paragraph**: This appears as "**Tips and Info**" in the top right corner of the application. When clicked, it will display a sidebar with the Title and Paragraph that you configured here. Use this section to provide any additional information that would help the student when completing this section.

**How “Are requests required?” Works on Request for Info Forms**

You’ll see the "**Are requests required?\"** setting in two places:

1. In the **general form settings**
2. On each **conditional logic rule** you create

**Here’s the difference:**

* **General:** This is the fallback. If you don’t add any conditions, this setting decides whether everyone must complete the form (**Required**) or if it’s optional (**Not Required**).
* **Conditional Logic:** If you add conditions, each condition gets its own toggle. If a student meets a condition, that condition decides whether the form is required or optional for them.

**What This Means:**

* If you want the form to be **required for everyone who meets the conditions**, simply set the condition(s) to **'Required'**. The general setting doesn’t matter in that case.
* If you want the form to be **optional** for certain groups, set the condition(s) to **'Not Required'**, even if the general setting is **'Required'**.
* Think of the **general setting as the fallback** (when no conditions apply).

# Cloning an Information Request Form

If you need a new Information Request form that's similar to an existing one, you can duplicate it rather than recreating it from scratch. This is helpful when you maintain several requests that share the same questions, such as different graduate programs that each need a transcript or reference request.

1. Navigate to **Applications** > **Applications** > **Request** **Information**.
2. Locate the form you want to copy and select **Duplicate** from its actions (alongside **Edit** and **Delete**).
3. A copy is created with the same applicant form, recommender form, confirmation messages, and autoresponder settings.
4. Click the **pencil icon** on the copy to rename it and adjust anything you need, then save.

📙 **Note:** The duplicated form is independent and isn't attached to any application until you add it to one (see [Step 3](#h_fe48f146cb) above).

# Deleting Submitted Requests

Administrators can delete a submitted letter of recommendation from an un-submitted application—for example, if a recommender uploaded an incorrect document and needs to submit a corrected version.

To delete a submitted letter of recommendation:

1. Navigate to the applicant's contact record.
2. Locate the **Info Requests** card.
3. Click the trash can icon on the letter of recommendation request you want to remove.

***Note:***This action requires both the **Administer Application** and **Delete User Application** permissions. Letters of recommendation can only be deleted while the application is un-submitted. Deletion is permanent.

# FERPA Waiver

By default, the system includes a waiver question at the bottom of the applicant's form. This question **cannot** be edited or removed. It asks, “Do you waive your right to view information sent on your behalf?” and requires a yes or no response.

🚨 **Important:** Regardless of the applicant's selection, the recommender’s response is not displayed to the student through the platform. If the student wants to view the recommendation, they must request and obtain it directly from your institution. You can verify their waiver response by following the instructions [below](#h_4fbb96b4d4).

[![](https://downloads.intercomcdn.com/i/o/1072708199/f0194e978f6424bb149b9e83/Screenshot+2024-06-05+at+12_27_42%E2%80%AFPM.png?expires=1784333700&signature=b5fa05b84782a803df826eb1a51486a67f08945c53fe281903eda0bbbe8b0018&req=dSAgFM5%2BlYBWUPMW1HO4zTvPiS6KtFPa8iBcniH%2B5vmLH2zylJCFBdDM86ft%0A2K3%2BYgnxxWUvnGjpSew%3D%0A)](https://downloads.intercomcdn.com/i/o/1072708199/f0194e978f6424bb149b9e83/Screenshot+2024-06-05+at+12_27_42%E2%80%AFPM.png?expires=1784333700&signature=b5fa05b84782a803df826eb1a51486a67f08945c53fe281903eda0bbbe8b0018&req=dSAgFM5%2BlYBWUPMW1HO4zTvPiS6KtFPa8iBcniH%2B5vmLH2zylJCFBdDM86ft%0A2K3%2BYgnxxWUvnGjpSew%3D%0A)

The response **determines which [autoresponder message](#h_8426a5aad3) is sent to the recommender**—“Document Request with Waiver” or “Document Request without Waiver.” At the bottom of the autoresponder, the following text is added by default, but you can edit it if needed:

* **Document Request with Waiver**: In accordance with the Family Education Rights and Privacy Act (FERPA) of 1974, [user:user-first-name] has waived [user:user-gender-pronoun,type=possessive] right to access this reference or recommendation.
* **Document Request without Waiver**: In accordance with the Family Education Rights and Privacy Act (FERPA) of 1974, [user:user-first-name] has not waived [user:user-gender-pronoun,type=possessive] right to access this reference or recommendation.

You can read more about autoresponders in [Step 2](#h_d5c0090e86) above.

## How-To: Find a Student's Waiver Response

1. Navigate to the student's profile.
2. Open/expand the **Activity** profile card.
3. Click **Info Request** from the left-hand menu.
