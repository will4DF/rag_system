Learn how to view and manage segments, including applying labels, exporting, and deleting.

# Overview

Once you've created Segments in the [People](https://help.element451.com/en/articles/1474208-creating-a-segment) module, you can manage them in the Segments module.

The Segments module also provides a list of your existing segments along with a bit of information about each:

* The Segment name
* Segment tags
* When it was last modified
* When it was created
* Who created it
* Workflows using the Segment

Segment information can be viewed and updated. Actions can also be performed on the Segment.

# Organizing Your Segments

## Organizing By Folders

### Create a New Folder

By default, you will have an "**All Segments**" folder and a "**Calculated** **Segments**" folder. However, you can create custom folders to organize your segments.

1. Click the **plus sign icon** from the folder menu.
2. Input a name for the folder and click **Submit** to save.

   [![](https://downloads.intercomcdn.com/i/o/898707651/ff15a43d46260d6bac7e08ce/Screenshot+2023-12-01+at+4.16.30%E2%80%AFPM.png?expires=1784333700&signature=aa9b7e544d9eb3b51c97f3fd0a76452632a5a0af54c3bcf23f8d8540b4797b19&req=fCkvEcl5m4ReFb4f3HP0gAqq7tpiBX7n5aWwZqVESp4zCFa0yr%2B9AVHA9kxS%0A%2Bkw%3D%0A)](https://downloads.intercomcdn.com/i/o/898707651/ff15a43d46260d6bac7e08ce/Screenshot+2023-12-01+at+4.16.30%E2%80%AFPM.png?expires=1784333700&signature=aa9b7e544d9eb3b51c97f3fd0a76452632a5a0af54c3bcf23f8d8540b4797b19&req=fCkvEcl5m4ReFb4f3HP0gAqq7tpiBX7n5aWwZqVESp4zCFa0yr%2B9AVHA9kxS%0A%2Bkw%3D%0A)

### Move Segment to Folder

1. With the folder created, locate the Segment you wish to add to the folder.
2. Click the **three-dot menu** to the far right of the Segment.
3. Select **Move to**.
4. Select your folder from the list and click **Move** to move the Segment into the folder.

   [![](https://downloads.intercomcdn.com/i/o/898713085/7a855bbd695e7bcae919f841/Move.png?expires=1784333700&signature=1aefc312d53bf0883b225ff4dd46100ac0b779097151a1897516376fa9293553&req=fCkvEch9nYlaFb4f3HP0gHtBSK9PMbae7xtL5K93Wkeq0q9XgxA4yB8jzfkZ%0AdMI%3D%0A)](https://downloads.intercomcdn.com/i/o/898713085/7a855bbd695e7bcae919f841/Move.png?expires=1784333700&signature=1aefc312d53bf0883b225ff4dd46100ac0b779097151a1897516376fa9293553&req=fCkvEch9nYlaFb4f3HP0gHtBSK9PMbae7xtL5K93Wkeq0q9XgxA4yB8jzfkZ%0AdMI%3D%0A)

## Organizing by Tags

Tagging a segment will help you find it later. This is extremely helpful if you have or eventually have an extensive list of segments. **Segment tags are specific to the Segments module.**

### Attaching a Tag to a Segment

1. Click **Add Tags** to the far right of the Segment name.
2. Choose from the list and click **Add**.

Once Tags are added, use the [filter control](#h_823ed2315d) to filter the list of Segments.   
​

[![](https://downloads.intercomcdn.com/i/o/898715005/0aedc175e21f125f0641379c/Screenshot+2023-12-01+at+4.33.40%E2%80%AFPM.png?expires=1784333700&signature=0fe00ceff1c6e673a3d6d13b411516f00e9168122068c554f8314711d11977a6&req=fCkvEch7nYFaFb4f3HP0gHIg4i35aU8eZxnBOl6lSR59ZNYwJdjPR8WFBBo4%0A55zEUZapqKll0ly1cw%3D%3D%0A)](https://downloads.intercomcdn.com/i/o/898715005/0aedc175e21f125f0641379c/Screenshot+2023-12-01+at+4.33.40%E2%80%AFPM.png?expires=1784333700&signature=0fe00ceff1c6e673a3d6d13b411516f00e9168122068c554f8314711d11977a6&req=fCkvEch7nYFaFb4f3HP0gHIg4i35aU8eZxnBOl6lSR59ZNYwJdjPR8WFBBo4%0A55zEUZapqKll0ly1cw%3D%3D%0A)

### Managing Tags

A dedicated **Tag Management** section in the left sidebar (below **Folders**) gives administrators a single place to create, rename, and delete segment tags. This works similarly to **Campaign Tags**.

* **Create a tag:** Click the **+** icon in the Tag Management section header, enter a name, and save.
* **Edit or delete a tag:** Click the **three vertical dots** next to the tag name and select **Edit** or **Delete** from the menu. Deleting a tag removes it from every segment it was attached to.

### Tag Permissions

Tag actions are split across two permissions so admins can control who manages the tag library separately from who can apply tags to segments:

|  |  |
| --- | --- |
| **Permission** | **What it allows** |
| **Administer Segment Tags** | Full CRUD on tags — create, edit, and delete |
| **Edit Segment** / **Administer Segment** | Attach and detach tags on segments (no create/edit/delete) |

📙 **Note:** The Tag Management section in the sidebar only appears for users with the **Administer Segment Tags** permission.

# Adding & Removing Labels to Students in a Segment

The Segments module allows you to apply a Label to all students in the Segment quickly.

1. Click the **three-dot icon** to the far right of the Segment.
2. Select **Add Labels** from the menu.
3. Select the Labels you wish to apply and click **Done** to save.
4. The system will begin adding the Labels to each student in the Segment. Allow a few minutes for this process to be complete.

To remove a Label, follow the same process. Select "Remove Label" from the menu.  
​

[![](https://downloads.intercomcdn.com/i/o/898713426/42dada41c3180a2013e25d3f/Remove+Labels.png?expires=1784333700&signature=45c974c48dc66bcd1653dc4efc4d3de3c631d25ede363d00d685b7e52ac6c6cc&req=fCkvEch9mYNZFb4f3HP0gC1WkeaQKS3cGQmSTsephL%2Fa3gVGU4x9X172d5fo%0AN6Nyid%2FRAIpYlmWjKQ%3D%3D%0A)](https://downloads.intercomcdn.com/i/o/898713426/42dada41c3180a2013e25d3f/Remove+Labels.png?expires=1784333700&signature=45c974c48dc66bcd1653dc4efc4d3de3c631d25ede363d00d685b7e52ac6c6cc&req=fCkvEch9mYNZFb4f3HP0gC1WkeaQKS3cGQmSTsephL%2Fa3gVGU4x9X172d5fo%0AN6Nyid%2FRAIpYlmWjKQ%3D%3D%0A)

# Deleting a Segment

This will permanently delete the Segment, but all student records formally in the Segment will still exist.

1. Click the **three-dot icon** to the far right of the Segment.
2. Select **Delete** from the menu.
