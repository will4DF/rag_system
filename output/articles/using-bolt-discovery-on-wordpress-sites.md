# Overview

Did you know you can seamlessly add Bolt Discovery (AI-powered search) to your WordPress site? With the [Element451 Plugin for WordPress](https://intercom.help/element451/en/articles/10423713-element451-integration-plugin-for-wordpress), you can easily integrate Bolt Discovery without requiring manual code embedding.

This plugin allows you to:

* Add [Bolt Discovery](https://help.element451.com/en/articles/9331910-bolt-discovery-overview) anywhere on your site using a block or shortcode—perfect for your header, footer, or main content areas.
* Combine Bolt Discovery with [Messenger (Live Chat**)**](https://help.element451.com/en/articles/6249763-messenger-live-chat#h_d8929b67c8) to enhance visitor engagement.

For detailed instructions on how to use the plugin and add Bolt Discovery to your WordPress site, check out our main help article.
