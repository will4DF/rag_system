# Overview

## What are Integration Mapping Templates?

Many platforms allow data to be downloaded as a .csv, .txt, or .pdf file. You can often schedule the frequency of these downloads and the location where the files are sent.

This common functionality allows Element451 to facilitate "flat file" integrations with these platforms via the [Imports + Exports module](https://help.element451.com/en/collections/8561605-import-export).

You can build your own integrations, but if you use popular platforms or services, you may be able to utilize Import Templates that Element451 has already built. Many platforms provide a standardized layout for their data file downloads. Element451 has sourced many of the standard layouts and used them to generate templates.

# FAQs

* **What is an integration mapping template?** A mapping template is a set of rules that "map" a given column in a data file to a location on an Element451 contact record. Templates can easily be applied to Import + Export Tasks and reused multiple times.   
  ​

  [Learn More: Using Templates in Import + Exports](https://help.element451.com/en/articles/9001231-creating-imports#h_d4d5c816b1)

* **Can Element451 integrate with other platforms not listed here?** Yes! Element451's Import + Export feature supports data and document files.
