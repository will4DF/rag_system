# Overview

Bolt AI is Element451’s suite of AI-powered tools designed to support both your team and your students. Whether creating drip campaigns, reviewing applications, answering student questions, or drafting content, Bolt AI is there to help you work faster and smarter.

## Bolt AI Features

Bolt AI is organized into three categories: **Bolt Agents**, **Bolt Staff Agents**, and additional **Bolt AI Tools**. Below, we explain each category.

---

# Bolt Agents

Bolt Agents are public-facing, conversational AI tools that act as frontline teammates for your staff. They’re designed to support prospective and current students, families, and alumni by providing instant answers, guidance, and support—24/7.

Each Agent is highly customizable and can be trained to handle specific types of student interactions. You can configure multiple agents with distinct roles, skill sets, and permissions to reflect real-life support structures, like Admissions, Financial Aid, or Academic Advising.

## Key Capabilities

* Bolt Agents are multichannel and multilingual. Using the Conversations module, they can engage across chat, SMS, email, and phone/voice. This ensures students and families receive consistent support no matter how they reach out.
* Integration with the People module to access records and activity to personalize conversations based on student data.
* Access to your self-curated Knowledge Hub for institution-specific answers.
* Configurable skills like application support, event registration, appointment scheduling, and more.
* Visibility rules control when and where agents appear.
* Optional handoffs to staff when needed.

# Bolt Staff Agents

Bolt Staff Agents are more than just internal tools—they’re your AI-powered partners inside Element451. Staff Agents use advanced large language models (LLMs), including enterprise versions of models from OpenAI and Google, to help your team streamline workflows, save time, and focus on high-priority work.

Staff Agents are available throughout Element451 via a conversational sidebar interface and embedded tools in specific modules. From reviewing applications and managing tasks to building campaigns and drafting content, Staff Agents can help you move faster and work smarter.

## Key Capabilities

* Seamlessly integrated within the Element451 interface via the Bolt Staff Agent Sidebar—accessible wherever you work.
* Context-aware intelligence that understands student records you view for more relevant assistance.
* Natural language processing that lets you ask questions, retrieve information, or generate content conversationally.
* Direct platform actions—create tasks, draft messages, update records, and more without switching contexts.
* Comprehensive knowledge access spanning both public and private Knowledge Hub repositories.
* Specialized Agent types (General, Campaigns, Copywriter, etc.) optimized for different tasks.
* Intelligent shortcuts and contextual prompts tied to specific records, tasks, or modules for enhanced efficiency.

## Staff Agent Types

|  |  |
| --- | --- |
| Bolt User Support Agent | Ask questions, retrieve student or user data, catch up on your tasks and assigned conversations, access your internal Knowledge Hub, and more. |
| Bolt Campaign Creator Agent | Draft subject lines and build full drip campaigns. |
| Bolt Copywriter Agent | Write content that aligns with your institutional brand style guide. |
| Bolt Page Builder Agent | Build branded, ready-to-publish pages with smart content generation. |
| [Beta] Bolt App Reader Agent | Provides a first-pass review of submitted applications, scoring them based on your admissions criteria to speed up evaluation and ensure consistency. |
| Bolt Fraud Detector Agent | Flags potentially fraudulent applications using AI to evaluate signals like submission timing, email patterns, and IP behavior. |
