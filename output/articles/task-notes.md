# Overview

After a task is created, you can add notes to keep track of updates or record important details. Notes can be added to both **internal** and **contact tasks**, ensuring all relevant information is documented.

For contact tasks, any notes added remain private and are not visible to the contact, allowing you to manage behind-the-scenes details effectively.

---

# Adding a Task Note

1. Navigate to **Contacts** > **Tasks**.
2. Locate the task for which you want to add a note.
3. Click on the **name** of the **task** to open the task editor.
4. Scroll down to the bottom and find the **Notes** section.
5. Type your note in the text box.
6. Once you're finished, click **Add**.

# Editing + Deleting a Note

1. Navigate to **Contacts** > **Tasks**.
2. Locate the task for which you want to add a note.
3. Click on the **name** of the **task** to open the task editor.
4. Scroll down to the bottom and find the **Notes** section.
5. On the note you wish to edit or delete, click the **three** **dots**.
6. Select either **Edit** or **Delete**.
