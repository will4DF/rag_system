# Education (124 fields)

Root Note: Does not require a root item when using an inline template. However, if you would like all education records, then you can use "user-education-schools-root" to allow repeating. Depending on the slugs selected, there may be blank data. For example, the response will have a "" value for a school name if you request High School name and the record has a college listed. CEEB Values: When importing a CEEB value, the system will attempt to match it with the CEEB record from our database. If a matching CEEB is found, all data for that CEEB record (name, address, type) will be populated for the student record and replace the imported data. Import Scope: When importing educational records, you can match a record on position, zip code or CEEB. However, CEEB is currently not exposed on the web interface. Just like any other scope, this would need to be added to every relevant field that is sent in the layout.
