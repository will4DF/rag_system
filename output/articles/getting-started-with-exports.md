Introductions to the Exports Feature

# Overview

Exporting People records is an important feature of reporting. This feature allows you to export data points from records in a customizable layout to assist with any reporting or integrating needs.

## Export Permissions

* **Access Import + Export**: The user has basic access to the import, export, and templates sections.
* **Administer Data Templates**: The user has access to create, edit, and delete import and export templates.
* **Administer Import + Export**: The user has access to create, edit, and delete import and export tasks.

[Read more on permissions →](https://help.element451.com/en/collections/3963257-permission-permission-groups)

## What Can Exports Do?

The Export feature is your tool to easily report out large amounts of data from records. Create lists of parents, students, and/or influencer records and all sorts of data on their profiles, including test scores, applications, sources, labels, decisions, schools, and more.

## Features

* **Segments**: Select a pre-built segment that you want to create a report for.
* **Repeat rows**: Decide if each row represents a record, application, test scores, and more
* **Destination**: Send the .csv or .txt file to an SFTP, Email, Google Drive, or Dropbox.
* **Preview**: View the input/outputs of the first few records to ensure data is in the intended format.

## Accessing Exports

To access **Import + Export**, navigate to **Data + Automations > Import + Export > Exports.**

# Export Management

The Import + Export screen is the main area for navigating between the import and export features and where you can see the comprehensive import and export tasks you and your team have created and ran. On the export screen specifically, you can:

* View all exports you and your team create
* Manage your exports tasks (edit, delete, duplicate)
* Apply quick filters to your export tasks
* Search for export tasks
* Assign export tasks to folders
