# Overview

Bolt Discovery thread history provides valuable insights into what your students and visitors are searching for, allowing you to tailor your communication and support strategies and improve your Knowledge Hub.

This information can be accessed in three distinct ways, each serving a different purpose:

1. **All Threads:** View and manage all threads, including advanced filtering and search capabilities.
2. **Contact Profile Card:** Access contact-specific threads to understand individual student or visitor needs.
3. **Bolt Discovery Insights Dashboard:** Analyze Bolt Discovery performance with comprehensive data visualizations and a detailed query log.

Below, we explain each method for accessing Bolt Discovery thread history:

---

# All Threads

To access all Bolt Discovery threads, navigate to **Engagement > Bolt Discovery > All Threads**. This page displays all threads in a format similar to the conversations inbox.

[![](https://downloads.intercomcdn.com/i/o/h9r2yo9x/1373793472/59eb1f3ecddc76f767b1389907d6/Discovery+-+All+Threads.png?expires=1784333700&signature=a145c9ca3812b23ce8946dad4d61f17e5f43a661e0cadecddc5e09fb3e4eb51c&req=dSMgFc53noVYW%2FMW1HO4zetmFKbbUL6UPTyVCr4VDsCtzS4vosNNTU7GRxH1%0AG%2BJas%2B4OixYc9SqmF1U%3D%0A)](https://downloads.intercomcdn.com/i/o/h9r2yo9x/1373793472/59eb1f3ecddc76f767b1389907d6/Discovery+-+All+Threads.png?expires=1784333700&signature=a145c9ca3812b23ce8946dad4d61f17e5f43a661e0cadecddc5e09fb3e4eb51c&req=dSMgFc53noVYW%2FMW1HO4zetmFKbbUL6UPTyVCr4VDsCtzS4vosNNTU7GRxH1%0AG%2BJas%2B4OixYc9SqmF1U%3D%0A)

**Key Features:**

* **Advanced Filtering:** Filter threads by person, handoff status, and lead form submission.
* **Search Functionality:** Search for specific threads using keywords or phrases.
* **Thread Details:** View the entire thread, thread starter (if known), and thread location.
* **Delete Threads:** Delete threads individually or in bulk using checkboxes.

# Contact Profile Card

To view contact-specific threads, ensure the Bolt Discovery [profile card is enabled](https://intercom.help/element451/en/articles/6449965-getting-started-with-profile-templates) [on your profile template](https://intercom.help/element451/en/articles/6449965-getting-started-with-profile-templates). Then, navigate to the desired contact's profile and locate the Bolt Discovery card.

[![](https://downloads.intercomcdn.com/i/o/h9r2yo9x/1373788972/5cde5cdd1533afcb4de164aa0c0e/Discovery+-+Profile+Card.png?expires=1784333700&signature=8cf4039db600756051014413485b787b29e313f86e6b0df1ad5e365cb42071ec&req=dSMgFc52lYhYW%2FMW1HO4zcEzCXX40Yslr%2F0NOXdw%2FBVuSceExoVBo%2FCwQZuU%0AHbc5Spz%2BRou6AhDbsn8%3D%0A)](https://downloads.intercomcdn.com/i/o/h9r2yo9x/1373788972/5cde5cdd1533afcb4de164aa0c0e/Discovery+-+Profile+Card.png?expires=1784333700&signature=8cf4039db600756051014413485b787b29e313f86e6b0df1ad5e365cb42071ec&req=dSMgFc52lYhYW%2FMW1HO4zcEzCXX40Yslr%2F0NOXdw%2FBVuSceExoVBo%2FCwQZuU%0AHbc5Spz%2BRou6AhDbsn8%3D%0A)

**Key Features:**

* **Contact-Specific Threads:** Access all threads initiated by a particular contact.
* **Search Functionality:** Search for specific threads using keywords or phrases.
* **Delete Threads:** Delete threads individually or in bulk using checkboxes.

# Bolt Discovery Insights Dashboard

The Bolt Discovery Insights Dashboard provides a comprehensive overview of Bolt Discovery's performance. To access the dashboard, navigate to Data + Automations > Insights > Discovery.

[![](https://downloads.intercomcdn.com/i/o/h9r2yo9x/1373785687/1607c9511bcbd6d220ba611c513a/Discovery%2B-%2BInsights.png?expires=1784333700&signature=04cd4b55bb466ca64980e2cdade2643dd0c6338d1dd1c9317df51e2e5d752a21&req=dSMgFc52mIdXXvMW1HO4zYMpBbgp%2FtFJLEvhLoTgYY%2F%2FpFuXEhg8OSiJQL%2FE%0AnK9vDEljgTOJzk3C918%3D%0A)](https://downloads.intercomcdn.com/i/o/h9r2yo9x/1373785687/1607c9511bcbd6d220ba611c513a/Discovery%2B-%2BInsights.png?expires=1784333700&signature=04cd4b55bb466ca64980e2cdade2643dd0c6338d1dd1c9317df51e2e5d752a21&req=dSMgFc52mIdXXvMW1HO4zYMpBbgp%2FtFJLEvhLoTgYY%2F%2FpFuXEhg8OSiJQL%2FE%0AnK9vDEljgTOJzk3C918%3D%0A)

​**Key Features:**

* **Performance Metrics:** View data on the number of threads, queries, Knowledge Hub sources referenced, Knowledge Hub gaps, and more.
* **Thread Metrics:** Analyze thread metrics by title and date.
* **Top Keywords and Sources:** Identify the most popular keywords searched and Knowledge Hub sources referenced.
* **Query Log:** Review individual questions asked and the responses provided by Bolt Discovery.
* **Thread Links:** Access links to explore entire threads from the query log.
* **Filtering Controls:** Filter data by date, previous period, category, Knowledge Hub gap, and other criteria.
