# Overview

The Tasks Performance dashboard allows you to monitor your team’s performance with Tasks. You can explore trends by Tasks Created, Due, Incomplete & Complete.

The Tasks Performance dashboard is also designed to give visibility to all staff and teams. For this reason, staff names and titles aren't displayed. To see individual staff performance, see the [Management dashboard](https://help.element451.com/en/articles/7436092-management-dashboard).

## Accessing the Dashboard

The Insights module can be accessed from the Data + Automations dropdown in the top navigation.

---

# **Dashboard Features**

Data can be viewed by overall performance, specific time frames, and/or within a subset of teams, staff members, tasks, and more.

## Global Controls

* Start Date and End Date | Filter all visualizations between dates.
* Primary Team | Filter by one or more Primary Team.
* Task Type | Filter by one or more task types. [Task types](https://help.element451.com/en/articles/3096969-creating-task-types) are set up under the settings section.
* Task | Filter by one or more task names.
* Display Results By | Group certain visualizations by day, week, month, or year.

## Drill Down Feature

The heat maps and bar charts in this dashboard have drill down options to toggle between task type and name or team and staff member. To change dimensions, click on the visualization and click the arrows in the top right corner.

# **Tabs**

Data on the Tasks Performance Board is organized by overall trends and the individual task metrics—creation, completion, and incompletion.

## Task Trends

* Task Trends

  + Key performance indicators on task created, tasks due, task completed, completion rate, and on-time completion rate in the selected time period. Note that some metrics—like task creation and completion—cannot account for the future. If the date range goes into the future, the creation and completion metrics will only go up until today's date.
* Task Insights

  + Multiple top 5 insights displaying top tasks that were created, due, and completed, teams with the most tasks completed, and lowest on-time completion.

## Task Creation

* Key performance indicator for tasks created in the selected time period
* Top 5 insights of the task names that were created the most during the selected time period.
* Heat map of when tasks get created the most by day of the week and hour
* Bar charts of creation counts each day broken down by task dimensions. These visualizations have the drill-down feature to change task dimensions.
* A heat map showing task creation counts by team and task type or task name for the selected time period. This visualization has a drill-down feature to change task dimensions.
* A task log with all tasks created during the selected time period. The columns are color-coded to indicate their due date. Blue represents upcoming tasks, green represents tasks completed, orange represents tasks due today, and red represents overdue tasks.

## Due Tasks

* Key performance indicator for tasks due in the selected time period.
* Top 5 tasks due in the selected time period.
* Top 5 teams with the most tasks due during the selected time period.
* Heat map of task due counts by team and task type or task name. This visualization has the drill-down feature to change task dimensions or staff member dimensions.
* Bar charts of task due counts each day broken down by task dimensions. These visualizations have the drill-down feature to change task dimensions or staff member dimensions.
* Task table that is grouped by team with task metrics.
* Task table that is grouped by type and name with task metrics.

## Incomplete Tasks

* Key performance indicators of tasks due, incomplete tasks, and completion rate in the selected time period.
* Stacked bar combo chart that displays the number of tasks due, their status, and the completion rate.
* Horizontal bar charts of incomplete task counts broken down by task dimensions. These visualizations have the drill-down feature to change task dimensions or staff member dimensions.
* Task log of incomplete tasks that are color-coded to indicate their due date. Blue represents upcoming tasks, orange represents tasks due today, and red represents overdue tasks.

## Task Completion

* Key performance indicators for tasks due in the time period, total tasks completed regardless of due date, total due tasks completed before today's date, and total due tasks completed on time
* Bar chart of tasks completed by type or name. This visualization has a drill-down feature to change between task type and name.
* Key performance indicators for on-time completion rate, average days budgeted for tasks, and average days taken to complete tasks. The budgeted and actual days taken can help decide if the duration of a task should be increased or decreased.
* Heat map of task completion time by day of the week and hour of the day.
* 2x2 chart displaying average days to complete tasks and on-time completion rate by type or name. The size of the data point represents the number of tasks completed. The location of the data point on the x-axis is the average amount of days to complete the task. The location of the data point on the y-axis is the on-time completion rate. Data points located in the bottom half, meaning the on-time completion rate is lower, should be given more time to complete. This visualization has the drill-down feature to change between task type and name.
* Horizontal bar charts comparing the budgeted days and the actual duration of completing a task. These visualizations have the drill-down feature to change between task type and name.

# **Troubleshooting & FAQ**

* ### Why is there no data?

  There are a variety of reasons an Insights report is blank. Try the following quick fixes:  
  ​

  + **Reset the report.** Visualizations may be filtering the report. Check the date controls. If the date is too far in the past, it may pre-date your activity in Element451.
  + **Check what fields are being used**.
  + If data is still missing, there may be issues with your data in Element. Check out [this guide](https://help.element451.com/en/articles/4404458-a-guide-for-data-clean-up) for data cleanup.
* ### **How often does the Tasks dashboard update?**

  The Tasks dashboard refreshes every 12 hours, between 5:00 AM and 6:00 PM EST. If team members complete tasks, create new ones, reassign tasks, etc., changes will be reflected in Insights around those times.
