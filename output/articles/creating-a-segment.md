Learn about the two ways to create a segment and pick which is best for you.

# Overview

In this article, we will discuss two ways to create a segment - building one from scratch with new filters or using an existing segment as a foundation.

⚠️ It is important to understand how filters work before creating a segment. Please review our [filter documentation](https://help.element451.com/en/articles/1476084-how-are-filters-used) before proceeding.

---

# Option 1: Add Filters

1. To create a new segment using filters, navigate to **Contacts** > **People**.

   [![](https://downloads.intercomcdn.com/i/o/898682305/95e3581fadf7fadd2a123c96/Screenshot+2023-12-01+at+3.25.26%E2%80%AFPM.png?expires=1784333700&signature=c238864041d7276e5bfdfedb3356f022fa0a9cfde576dd139f0ac408007e201c&req=fCkvEMF8noFaFb4f3HP0gNSsAcV4LHP6ScbgsuNS8DFv%2FG%2FdjHrzKHAZpN3A%0Aevs%3D%0A)](https://downloads.intercomcdn.com/i/o/898682305/95e3581fadf7fadd2a123c96/Screenshot+2023-12-01+at+3.25.26%E2%80%AFPM.png?expires=1784333700&signature=c238864041d7276e5bfdfedb3356f022fa0a9cfde576dd139f0ac408007e201c&req=fCkvEMF8noFaFb4f3HP0gNSsAcV4LHP6ScbgsuNS8DFv%2FG%2FdjHrzKHAZpN3A%0Aevs%3D%0A)
2. Click **Add Filter**.

   [![](https://downloads.intercomcdn.com/i/o/898683615/83b81163fea5661611e473cd/Screenshot+2023-12-01+at+3.27.05%E2%80%AFPM.png?expires=1784333700&signature=9eba8de17802ba07b59833c018725cb4a470fbdc2c61912b0f6969c8b80b5051&req=fCkvEMF9m4BaFb4f3HP0gCMf5GXUJ0yQKDL0HBGVvN4kNDkbcW6ZcSGEBte8%0ASVY%3D%0A)](https://downloads.intercomcdn.com/i/o/898683615/83b81163fea5661611e473cd/Screenshot+2023-12-01+at+3.27.05%E2%80%AFPM.png?expires=1784333700&signature=9eba8de17802ba07b59833c018725cb4a470fbdc2c61912b0f6969c8b80b5051&req=fCkvEMF9m4BaFb4f3HP0gCMf5GXUJ0yQKDL0HBGVvN4kNDkbcW6ZcSGEBte8%0ASVY%3D%0A)
3. Select a property from the list or use the **Find Filter** bar to search for a property. You can also narrow the list by choosing a Type from the drop-down menu at the top. For this screenshot, we have selected **Tasks** as the Type.  
   ​  
   The property types are Popular, Users, Activity, Relationships, Tasks, Decisions, Documents, Surveys, and Appointments. You can learn more about filters [here](https://help.element451.com/en/articles/1476084-how-are-filters-used).  
   ​

   [![](https://downloads.intercomcdn.com/i/o/898686801/5f157c814bc3c344177381c4/Screenshot+2023-12-01+at+3.33.14%E2%80%AFPM.png?expires=1784333700&signature=e58f4eb9d5fe410b68b5a6361a487f961b73e3ec148f4c3ecf55be3322b867a7&req=fCkvEMF4lYFeFb4f3HP0gL6aUNMmSAL1WN31R6WXo4EtA7NXxgjrhRnf10H8%0A%2B6A%3D%0A)](https://downloads.intercomcdn.com/i/o/898686801/5f157c814bc3c344177381c4/Screenshot+2023-12-01+at+3.33.14%E2%80%AFPM.png?expires=1784333700&signature=e58f4eb9d5fe410b68b5a6361a487f961b73e3ec148f4c3ecf55be3322b867a7&req=fCkvEMF4lYFeFb4f3HP0gL6aUNMmSAL1WN31R6WXo4EtA7NXxgjrhRnf10H8%0A%2B6A%3D%0A)
4. To build your Segment, add as many filters as needed. After adding a filter, click the blue **Apply** button to apply the filter and see the results.
5. When you have applied all the filters you want, you can save the Segment by clicking the **Save as New Segmen**t icon to the right below your filters.   
   ​

   [![](https://downloads.intercomcdn.com/i/o/898690063/8ca15c2f9c0ddac4968583cd/Screenshot+2023-12-01+at+3.38.14%E2%80%AFPM.png?expires=1784333700&signature=6030e31a5f0698f892a5c6b9e1608a034fe0223d61e436279afb1e0a1ca93305&req=fCkvEMB%2BnYdcFb4f3HP0gB4WwpussPNZdM%2FoZPR%2BXWDz9T7Af%2B70Skv5K1Q9%0Ax4o%3D%0A)](https://downloads.intercomcdn.com/i/o/898690063/8ca15c2f9c0ddac4968583cd/Screenshot+2023-12-01+at+3.38.14%E2%80%AFPM.png?expires=1784333700&signature=6030e31a5f0698f892a5c6b9e1608a034fe0223d61e436279afb1e0a1ca93305&req=fCkvEMB%2BnYdcFb4f3HP0gB4WwpussPNZdM%2FoZPR%2BXWDz9T7Af%2B70Skv5K1Q9%0Ax4o%3D%0A)
6. Saved Segments can later be reloaded and used in other Element451 modules. You can manage saved segments by navigating to **People** > **Segments**.

💡 Tip: For advanced segment configuration, consider using [Any + All Operators](https://help.element451.com/en/articles/3648165-filters-all-any-operators) to your filters.

# Option 2: Load a Segment

If you want to create a Segment similar to one that already exists efficiently, we recommend using the **Load a Segment** option. This way, you can modify an existing Segment rather than re-building it from scratch.

1. Navigate to **Contacts** > **People**.

   [![](https://downloads.intercomcdn.com/i/o/898682305/95e3581fadf7fadd2a123c96/Screenshot+2023-12-01+at+3.25.26%E2%80%AFPM.png?expires=1784333700&signature=c238864041d7276e5bfdfedb3356f022fa0a9cfde576dd139f0ac408007e201c&req=fCkvEMF8noFaFb4f3HP0gNSsAcV4LHP6ScbgsuNS8DFv%2FG%2FdjHrzKHAZpN3A%0Aevs%3D%0A)](https://downloads.intercomcdn.com/i/o/898682305/95e3581fadf7fadd2a123c96/Screenshot+2023-12-01+at+3.25.26%E2%80%AFPM.png?expires=1784333700&signature=c238864041d7276e5bfdfedb3356f022fa0a9cfde576dd139f0ac408007e201c&req=fCkvEMF8noFaFb4f3HP0gNSsAcV4LHP6ScbgsuNS8DFv%2FG%2FdjHrzKHAZpN3A%0Aevs%3D%0A)
2. Click on the **Segment** box located right under the word People.   
   ​

   [![](https://downloads.intercomcdn.com/i/o/898694064/54cdf7ad6a3532ff6726dc21/Screenshot+2023-12-01+at+3.47.48%E2%80%AFPM.png?expires=1784333700&signature=85679fe29d0f86e21aebd30f40fce81dba2958aebc32a8ce0cb65bf9158ea6fe&req=fCkvEMB6nYdbFb4f3HP0gIO3%2FY4QqOqdS0feIEGzwGPRno2ppmLwvh8B%2B0Zb%0Apwg%3D%0A)](https://downloads.intercomcdn.com/i/o/898694064/54cdf7ad6a3532ff6726dc21/Screenshot+2023-12-01+at+3.47.48%E2%80%AFPM.png?expires=1784333700&signature=85679fe29d0f86e21aebd30f40fce81dba2958aebc32a8ce0cb65bf9158ea6fe&req=fCkvEMB6nYdbFb4f3HP0gIO3%2FY4QqOqdS0feIEGzwGPRno2ppmLwvh8B%2B0Zb%0Apwg%3D%0A)
3. Search for and select one of your existing segments.  
   ​

   [![](https://downloads.intercomcdn.com/i/o/898694631/e9d4865e60120f2c46920d72/Screenshot+2023-12-01+at+3.49.10%E2%80%AFPM.png?expires=1784333700&signature=67a3079afd03d1e527c78cdcf279308a8fc037e87e0ddd879d7480f06985afde&req=fCkvEMB6m4JeFb4f3HP0gK6lM0RiWmgjSaFHKQjv6niMVZ05FbQVkcDGpxnn%0ABuY%3D%0A)](https://downloads.intercomcdn.com/i/o/898694631/e9d4865e60120f2c46920d72/Screenshot+2023-12-01+at+3.49.10%E2%80%AFPM.png?expires=1784333700&signature=67a3079afd03d1e527c78cdcf279308a8fc037e87e0ddd879d7480f06985afde&req=fCkvEMB6m4JeFb4f3HP0gK6lM0RiWmgjSaFHKQjv6niMVZ05FbQVkcDGpxnn%0ABuY%3D%0A)
4. Once selected, the segment will load. Add to or adjust the filters as needed.
5. When you are finished, click **Save as New Segment**. Or, if you change your mind, you can also close the segment so as not to save the modified Segment.
