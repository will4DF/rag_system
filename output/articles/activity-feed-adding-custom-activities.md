Learn how to track relevant custom activities on the student's profile using manual and automatic processes.

# Overview

The activity feed allows you to keep track of a student's entire recruitment journey. [Learn the basics of the Activity Feed here](https://help.element451.com/en/articles/5159877-activity-feed-the-student-s-journey).

The system automatically logs many actions, but there may be situations where you might want to monitor additional activities. This guide explains why and how to add these activities to a student's profile.

Activities are sorted into default categories, but you have the flexibility to use these categories or craft your own. [Discover how to create custom activity types here](https://help.element451.com/en/articles/3096969-activity-task-and-note-types).

---

# Why Add Activities?

## Logging Offline Interactions/Activities

Many relevant activities to a student's recruitment journey happen offline. Perhaps they attended an event not captured in the system, or their assignee might have called them.

Staff-initiated actions like calls are typically tracked as Tasks, so staff will have a future reminder. When marked complete, the Task is added to the student's activity feed automatically. For instances where you don't need the future reminder, you can add the completed call directly to the activity feed**.** Follow the steps below to log the offline activity manually.

## Logging Activities in Other Systems

Activities logged in different systems can be crucial for a student's record. Integrating these activities into Element451 is beneficial for segmenting and comprehensively viewing the student's recruitment journey. Below are steps to explore how to merge activities from other systems into Element451.

# Adding Activities

## Manually Adding Activities

Activities can be manually added to the student's record via the Activity card.

📙 ***Note****: You must have an activity card displayed on your profile template.*

*[Learn more about Bolt Profile Templates](https://help.element451.com/en/articles/1475735-the-person-profile).*

1. Navigate to **Contacts** > **People** or use the search bar in the top right corner to search the student's name.
2. Click on their name to open the profile.
3. Look for the **Activity** card on the user profile. You can also search for it using the search bar.
4. Click the **plus** **sign** in the top right corner of the Activity Card to add activity.

## Adding Activities Automatically via Workflows

Activities can be automatically added to a student's record via Workflows or Rules.

📙 ***Note:*** Before starting this process, we recommend having a good understanding of creating Workflows and Rules. You can learn more about these in the [Workflows + Rules Collection](https://help.element451.com/en/collections/124560-workflows-rules) of the Help Center.

To create a Custom Activity as part of a Workflow:

1. Add a new Action to a Workflow step
2. Select **Add** **Custom** **Activity** as the Action Type.  
   ​

   [![](https://downloads.intercomcdn.com/i/o/936257538/36669c29bdf26014bd0ad5ce/Screenshot+2024-01-17+at+12.14.36%E2%80%AFPM.png?expires=1784333700&signature=9f70babd93ffec55e56320b3c2fa2c6afbc990335250b025ddaa22d3f3ea998d&req=fSMhFMx5mIJXFb4f3HP0gN4oIEmoYstr0hx1uUbi7eoKoxSFly9BT454GGT2%0Ank4%3D%0A)](https://downloads.intercomcdn.com/i/o/936257538/36669c29bdf26014bd0ad5ce/Screenshot+2024-01-17+at+12.14.36%E2%80%AFPM.png?expires=1784333700&signature=9f70babd93ffec55e56320b3c2fa2c6afbc990335250b025ddaa22d3f3ea998d&req=fSMhFMx5mIJXFb4f3HP0gN4oIEmoYstr0hx1uUbi7eoKoxSFly9BT454GGT2%0Ank4%3D%0A)
3. Then, complete the Custom Activity fields:

   * **Date Completed** (Enter a date in the past. If no date is entered, the activity will be logged at the date and time the workflow step runs)
   * **Name**
   * **Note**
   * **Type** (required)
4. When you're finished, click the Save button ![](https://downloads.intercomcdn.com/i/o/936247118/5c0b25120e546f12790812f6/Screenshot+2024-01-17+at+12.04.59%E2%80%AFPM.png?expires=1784430000&signature=e92389ae10841fac6e422785bad13bb613639aa392ca11ca7b2adb81084aa151&req=fSMhFM15nIBXFb4X1HO4gapoxIxE9HSFujt7v%2BUtWrora2fltCxOsiiGayg4%0A) in the top right corner.

💡**Tip**: Creating Custom Activities using Workflows is a great way to ensure Names and Notes are populated consistently.

## Adding Activities Automatically via the API

Element451 features an open API as part of our core product. The API allows you to manipulate data in Element451 via code instead of through the Element451 interface. Accessing the API will likely require the assistance of an IT team member or software developer. Learn more about Element451's API on [our documentation site](https://api.element451.com/) or via our [Integrations guide.](https://integrations.element451.com/)

To add a Custom Activity to a Record, use the ["Create User External Activity" POST request](https://api.element451.com/#e8d20332-f60e-416f-911d-fc60643b22c2). Include the item object in the body.
