Learn how to credit, edit, and delete custom permission groups as well as configuring document type and campaign restrictions.

# Overview

If you cannot find a [System Permission Group](https://help.element451.com/en/articles/2735389-permission-groups-overview#h_deeebe4fbe) to fit your needs, you can create your own Custom Permission Groups to tailor access exactly to your requirements. These groups allow you to select and combine specific [individual permissions](https://help.element451.com/en/articles/2735389-permission-groups-overview#h_92da3e4cb9), offering precise control over what actions users can perform.

This article guides you through creating, modifying, and deleting custom groups.

Note: It can take up to 60 seconds for permission updates to take effect.

# Creating a Custom Permission Group

1. In the top right of your screen, locate and click your **user profile image or icon**.
2. Navigate to **Settings** > **Manage Users** > **Permission Groups.**
3. Click the **+ New Permission Group** button ![](https://downloads.intercomcdn.com/i/o/979353734/4ad75026fc78a333d1ac1a4e/%2B+new+permission+group2.png?expires=1784430000&signature=87f443742e2edadd69a5889958c1a4a2c4a6ff7079f5ffa058498ad53bb03a0c&req=fScuFcx9moJbFb4X1HO4gUrvbg4jDaVHCcgc2DK4ZoREoBpn6lNFKS87huXY%0A) in the right corner of the header. A sidesheet will open for you to configure your new Permission Group.
4. Replace "**Group Name**" at the top with your chosen name.
5. Add a **Group Description** to help with identification purposes.

   [![](https://downloads.intercomcdn.com/i/o/979387882/a8533cf0b095d622b99bc69d/Permissions+-+Desc.png?expires=1784333700&signature=6d6c6914e6095d79cf6de32acc756b922d192bfc224d226ab676b7ec9d66bb9c&req=fScuFcF5lYldFb4f3HP0gELDdYU1cZht7uhSBp1ORolPkl70%2FgBCPMvIxA5M%0A1lU%3D%0A)](https://downloads.intercomcdn.com/i/o/979387882/a8533cf0b095d622b99bc69d/Permissions+-+Desc.png?expires=1784333700&signature=6d6c6914e6095d79cf6de32acc756b922d192bfc224d226ab676b7ec9d66bb9c&req=fScuFcF5lYldFb4f3HP0gELDdYU1cZht7uhSBp1ORolPkl70%2FgBCPMvIxA5M%0A1lU%3D%0A)
6. Click **+ Add Users**.   
   ​

   [![](https://downloads.intercomcdn.com/i/o/979379761/bc6bd7b6273713af45c132b7/Permissions+-+Users.png?expires=1784333700&signature=5d80aecf155fd2363e7470c78ce5bbdbd1e56e3f8f62710cff59c124ed0c99fd&req=fScuFc53modeFb4f3HP0gDTN9YaEllNJQH4hkef6mu22moe8ddCMCz8OOjJg%0At1g%3D%0A)](https://downloads.intercomcdn.com/i/o/979379761/bc6bd7b6273713af45c132b7/Permissions+-+Users.png?expires=1784333700&signature=5d80aecf155fd2363e7470c78ce5bbdbd1e56e3f8f62710cff59c124ed0c99fd&req=fScuFc53modeFb4f3HP0gDTN9YaEllNJQH4hkef6mu22moe8ddCMCz8OOjJg%0At1g%3D%0A)
7. Use the checkboxes to select one or more users to add to this Permission Group.

11. Once saved, the Group will appear in the list of Permission Groups available when editing a team member's user account.
12. Now that your Custom Permission Group is saved, you can add additional permissions specific to accessing **Document Types** and **Campaigns**. Continue reading for more information.

## Users

Add or remove users from this Permission Group.

* To add a user, click the **+ Add Users** button at the bottom of the page.
* To remove a user, click the ![](https://downloads.intercomcdn.com/i/o/910888780/681abf51f74be074b2d65046/Screenshot+2023-12-15+at+1.24.20%E2%80%AFPM.png?expires=1784430000&signature=de48a4d82f92c22408b388dc8934e675adb0be75a1104ac7a23e9446361d21da&req=fSEnHsF2molfFb4X1HO4gdzeAjfHjg7DATYTYpihz0e%2FFf3t0gpZdrDmJbnK%0A)(more settings icon) on the user's row and select **Delete**.

## Permissions

Edit the permissions within this Permission Group.

* Use the checkboxes to select the permissions you wish to add and deselect the ones you wish to remove. You can refer to [this article](https://help.element451.com/en/articles/6590379-list-and-details-of-each-permission-group) for more information on each permission.

## Restrictions Settings

### Document Types

This setting allows administrators to restrict the visibility of specific [Document Types](https://help.element451.com/en/articles/2433933-managing-document-types) for users within this Permission Group.

**To restrict Document Type visibility, follow these steps:**

⚠️ **Important:** You must complete **both** **steps** outlined below to enforce Document Type restrictions from the Permission Group.

1. Use the checkboxes to select the [Document Types](https://help.element451.com/en/articles/2433933-managing-document-types) that should be viewable by this permission group.  
   ​

   [![](https://downloads.intercomcdn.com/i/o/913712016/c622f1974180f9ee06a4d21c/Screenshot+2023-12-19+at+11.44.52%E2%80%AFAM.png?expires=1784333700&signature=031e2116cfb61c85fba5bf8f7e4620dc912f50bd2951ce01b7d2a824fdc071b3&req=fSEkEch8nYBZFb4f3HP0gCdcjeNDVeOg3FJLomhIVd%2FTbFSJ2EKZfscyFCXL%0AWKg%3D%0A)](https://downloads.intercomcdn.com/i/o/913712016/c622f1974180f9ee06a4d21c/Screenshot+2023-12-19+at+11.44.52%E2%80%AFAM.png?expires=1784333700&signature=031e2116cfb61c85fba5bf8f7e4620dc912f50bd2951ce01b7d2a824fdc071b3&req=fSEkEch8nYBZFb4f3HP0gCdcjeNDVeOg3FJLomhIVd%2FTbFSJ2EKZfscyFCXL%0AWKg%3D%0A)

### Case Management

This setting allows administrators to restrict the visibility of specific **[Alert Types](https://help.element451.com/en/articles/13772418-alert-settings-closed-beta)** and **[Case Types](https://help.element451.com/en/articles/13775536-case-settings-closed-beta)** for users within this Permission Group.

⚠️ **Important**: You must complete both steps outlined below to enforce Case Management restrictions from the Permission Group.

**To** **restrict** **Case** **Management** **visibility,** **follow** **these** **steps:**

**Step 1:** Select the checkboxes for the Alert Types and/or Case Types that should be viewable by users in this Permission Group. Users will only be able to see Alerts and Cases that match the selected types.

**Step** **2:** Enable the Case Management restriction on individual user accounts:

1. Navigate to **Settings** > **Manage** **Users**.
2. Select the person's name.
3. Click the **Restrictions** tab.
4. Toggle on **Case** **Management**.

# Troubleshooting Permission Updates

Please note that it can take up to 60 seconds for permission updates to take effect. If the permission change doesn’t seem to have taken effect, follow these steps:

* Wait an additional 90 seconds.
* Perform a hard refresh on your browser.

  + Windows (PC): Ctrl + Shift + R
  + Mac: Command + Shift + R
* Sign out, then sign back in.
* Clear your browser cache.
