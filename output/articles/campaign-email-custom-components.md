# Overview

Custom components in Element451 allow you to save and reuse **rows** in your email Campaigns, simplifying the process of including frequently used content like headers and footers.

![](https://downloads.intercomcdn.com/i/o/1068085589/01faab9185dd0762045ed5f6/Important+-+Orng.png?expires=1784430000&signature=6239c2df59c619592dd1efe41b994981b6f5db3549ab1db0cd35034a8ce7f224&req=dSAhHsl2mIRXUPMW3Hu4gZ2dig0wjpXJXNOdyGNvkhpNdxMZnTEtP%2BimSBUk%0A6w%3D%3D%0A) Custom components are not dynamic. If you update a custom component, like changing a social media URL in a footer, these changes will not automatically apply to other instances of the component in ongoing campaigns. You'll need to update each instance manually.

Custom Components will appear alongside other content block types when adding a content block to your Campaign.

# How to Insert a Custom Component

To insert a custom component, find the one you want, hover over it, and click "**Add Block**." It's as straightforward as adding any other content block.  
​

# How to Create a Custom Component

Custom components are created at the **row** **level**. To save a row as a custom component:

1. Hover over the row you wish to save as a custom component.
2. Click the **plus sign** at the top right corner of the row.   
   ​

   [![](https://downloads.intercomcdn.com/i/o/1068088781/4026604bb7691a513a397fd1/Screenshot+2024-05-31+at+1_53_58%E2%80%AFPM.png?expires=1784333700&signature=525672b9de375ffdc82befb71c2cffe69e1fc6648b673963fc4f205a9b24df7c&req=dSAhHsl2lYZXWPMW1HO4zfyKj%2BqJqgZTRtAsXxwL%2B%2FB23NCVJ5CMq2DYOG0I%0A25ta%0A)](https://downloads.intercomcdn.com/i/o/1068088781/4026604bb7691a513a397fd1/Screenshot+2024-05-31+at+1_53_58%E2%80%AFPM.png?expires=1784333700&signature=525672b9de375ffdc82befb71c2cffe69e1fc6648b673963fc4f205a9b24df7c&req=dSAhHsl2lYZXWPMW1HO4zfyKj%2BqJqgZTRtAsXxwL%2B%2FB23NCVJ5CMq2DYOG0I%0A25ta%0A)
3. Give your custom component a **Name**.
4. Click **Create**

---

# How to Edit a Custom Component

Custom Components cannot be edited directly. To make changes, add the component to a campaign, modify it as needed, and save it with a new name. You can then delete the original component if it's no longer needed.

---

# How to Delete a Custom Component

1. Find the component you wish to delete from the custom component list (when adding a content block).
2. Click the **trash can** icon to the right of the component's name.
