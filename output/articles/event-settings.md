Configure your global event settings including event types, categories and event series.

# Overview

The Events module settings provide configuration certain global event entities. This includes Types, Categories and Event Series.

---

# Event Settings

## Accessing Event Settings

1. Navigate to **Engagement** > **Events** > **Event** **Settings**.
2. In the left-hand column, you will see the menu of event settings.

### Types

Event Types are for internal use only. Each event can optionally be assigned a single type. Types are useful for segments and organizations, and they can also be used to assign events to one or more Event Sites.  
​

You can assign an Event Type using the drop-down menu in the header of the Event Overview page for the event when creating or editing an event.  
​

### Categories

Event Categories act as tags for events. Each event can have one or more categories assigned. Like types, categories can be used for segmentation and to assign events to one or more Event Sites.  
​

Visitors to your event site(s) can also use categories to filter event listings.  
​

You can assign an category from the header of the Event Overview page for the event when creating or editing an event.

### Event Series

Event Series are one way to group events with the common theme, audience or focus. You could build an event series around a group of lectures, admitted student events and more.

#### How To: Add a new

1. Navigate to **Engagement** > **Events** > **Event** **Settings.**
2. Click **Event Series** ![event series](https://downloads.intercomcdn.com/i/o/h9r2yo9x/2141503057/17d2b424476223ebfa39bfdeb5cf/image.png?expires=1784430000&signature=6b377f792e62035379697895cac6e2daf5f7eb548d4995fd3a2d0f733be72885&req=diEjF8x%2BnoFaXvMW3Hu4gTdYzJ%2FyUD8CThf9LVXQCsRgDzkJ6oYEHcpLbPdS%0A0A%3D%3D%0A) from the lefthand menu.
3. Click the plus button ![](https://downloads.intercomcdn.com/i/o/970339514/473ba2f4d7408eedcd204efd/%2B+Plus+Button+Transparent.png?expires=1784430000&signature=453bdd1ee273a429355a12e13330dcaf99a05075b1fe6aae4460df997095ab1c&req=fScnFcp3mIBbFb4X1HO4gcvACgPICtwmsiUon8FWfqQ2szO3twDCCbI3Zgv6%0A) in the bottom right.
4. Enter the text for the new series name, set the privacy and provide a description of your series.

#### How To: Edit or Delete Event Series

1. Navigate to **Engagement** > **Events** > **Event** **Settings.**
2. Click **Event Series** ![event series](https://downloads.intercomcdn.com/i/o/h9r2yo9x/2141503057/17d2b424476223ebfa39bfdeb5cf/image.png?expires=1784430000&signature=6b377f792e62035379697895cac6e2daf5f7eb548d4995fd3a2d0f733be72885&req=diEjF8x%2BnoFaXvMW3Hu4gTdYzJ%2FyUD8CThf9LVXQCsRgDzkJ6oYEHcpLbPdS%0A0A%3D%3D%0A) from the lefthand menu.
3. Click the pencil icon in the row to edit the series and add events.
4. Click the trash can to delete a Series.
