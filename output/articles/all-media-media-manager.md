# Overview

The Media Manager is a powerful feature in Element451 where you can upload, organize, and manage media (images, documents, etc.) for use in your Campaigns and Pages. This article will guide you through its key features and how to use them effectively.

## Key Features

* **Folders**: Organize your media into folders for easy access and management.
* **Tags**: Add tags to your media for quick filtering and searching.
* **AI-generated descriptions**: Automatically generate descriptions to help BoltAI select appropriate media when creating campaigns and pages.
* **Alt Text**: Add alternative text to images for improved accessibility and compliance.
* **Imgix URLs**: Access powerful image transformation options through Imgix integration.

## Accessing Media Manager

### Administer Media Manager permission

Default Access (WITHOUT the "Administer Media Manager" permission):

* Access to the Media Manager only when inserting media within a module that uses the Media Manager, such as Campaigns, Conversations, Events, and Pages (if the user has permission to access the modules).
* Select existing media for use in the respective module.
* View the *info section* of existing media files and use the download feature.
* Cannot upload, modify, or delete any media from the Media Manager, regardless of who added it.

Additional Access Granted by the "Administer Media Manager" permission:

* In addition to the default access described above, this permission grants:

  + Direct access to the Media Manager at **Data + Automations** > **Documents** > **All Media**.
  + Upload, modify (rename/move), and delete media.

This permission is part of the **Element451 Administrator** system permission group. However, administrators can also manually add this individual permission to [custom permission groups](https://help.element451.com/en/articles/9020578-creating-managing-custom-permission-groups).

To access the Media Manager:

Navigate to **Data + Automations** > **Documents** > **All Media.**

# Adding Media

1. Click the plus sign (+) in the blue circle located in the bottom right corner of the screen.
2. You'll see three options:

   * Create a new folder
   * Upload a file
   * Upload from Unsplash

To upload a single image:

1. Choose **Upload a file**.
2. Drag and drop or select the file you want to upload
3. Click **Add**.
4. The file will appear in your **All Files** section.

Folders help you organize your media files into logical groups. You can find the Folders section in the left sidebar of the Media Manager. Click on any folder to filter the view and see only the files stored in that folder.

## Tags

Tags allow you to label and categorize your files across folders. Unlike folders, a single file can have multiple tags, making it easy to find files that belong to more than one category. You can find the Tags section in the left sidebar below the Folders section. Click on any tag to filter the view and see all files associated with that tag.

### Creating + Managing Tags

* **To create a tag**: Click th**e + Add Tag** button at the bottom of the Tags list in the left sidebar. Enter a name for the tag and save.

# Image Tools and Integrations

## Unsplash Integration

Unsplash is integrated into the Media Manager to provide easy access to royalty-free, high-quality stock photos. To access Unsplash, when [adding a new file](#h_8ecfbd2ec3), select **Upload from Unsplash**. Simply search for what you need directly within the upload interface.

## imgix Transformations

Element451 leverages imgix to offer powerful image transformations. You can create custom image variations by simply adding parameters to your image's URL.

[Explore More on imgix →](https://help.element451.com/en/articles/6963949-image-transformations-with-imgix)

# Using Media in Other Modules Campaigns and Pages

You can add or insert an image in various modules across Element451 (e.g., Campaigns, Conversations, Events, and Pages).

1. You can select an existing image from your Media Manager.
2. Alternatively, you can upload a new image directly from the respective module (administer media manager permission required).
3. Newly uploaded images are automatically added to your Media Manager for future use.

This direct connection ensures that your media assets are always accessible and organized, whether working in the Media Manager or creating content in other modules.

# Best Practices

1. Use descriptive file names for easy identification.
2. Utilize folders to keep your media organized by campaign, theme, or content type.
3. Add relevant tags to make searching and filtering more efficient.
4. Always include alt text for images to improve accessibility.
5. Leverage Imgix transformations to optimize images for different use cases without creating multiple versions.

# Troubleshooting + FAQ

Q: I don't have an option to upload a new image.

A: If you are missing the upload tab when trying to add an image to a Conversation, Campaign, etc., you are likely missing the "Administer Media Manager" permission. Reach out to your Element451 administrator to review your permissions.
