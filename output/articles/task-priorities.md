# Overview

Task Priorities help you organize and manage tasks based on their level of importance. Within the setup page, you can create distinct priorities for both **internal tasks** and **contact tasks**.

You can use default priorities like **Low**, **Medium**, and **High** or create custom ones to fit your specific workflow. This flexibility helps you manage workloads effectively and ensures that both internal and contact tasks are prioritized accurately.

# Default Priority

Priority is a required field when creating a new task. To streamline manual task creation, Element451 admins can set a default Priority that will pre-populate the Priority field for all users. Use the drop-down field to change your Default Priority.

# Adding a Custom Priority

1. Ensure you are in the correct category in the left-hand menu—internal or contact.
2. Click the **+ Add New Priority button** at the bottom of the Priority list**.** ![](https://downloads.intercomcdn.com/i/o/911859548/057e867342b6e26754382839/Screenshot+2023-12-17+at+1.31.51%E2%80%AFPM.png?expires=1784430000&signature=cc93d9fefc36e4d71939fb5d76ed7985ca6096b9dbe8f264847198cb54b91cdc&req=fSEmHsx3mIVXFb4X1HO4gccdsOCnO6DDeFMoZWiZouRVgsTENVj%2B54yGolqF%0A)
3. Replace "**Untitled**" at the top with a name for your Status.
4. Enable or disable your Status by using the toggle.
5. Select the icon you wish to use to represent this Priority.
6. Select the color you'd like to associate this Priority with.
7. Click **Save**.

[![](https://downloads.intercomcdn.com/i/o/911859419/d2bcd6f5bb35b0919c946c11/Screenshot+2023-12-17+at+1.36.29%E2%80%AFPM.png?expires=1784333700&signature=c6935eb45c51b18b4a60f80b2e88ea9876b4438b0f31586af41c8a4655e44a52&req=fSEmHsx3mYBWFb4f3HP0gDfTm%2FjJG5Zn54bkik123HpLXMBnBUi9%2BH%2Fc85Xt%0AHPOnPxRrAWEJrpu9Yg%3D%3D%0A)](https://downloads.intercomcdn.com/i/o/911859419/d2bcd6f5bb35b0919c946c11/Screenshot+2023-12-17+at+1.36.29%E2%80%AFPM.png?expires=1784333700&signature=c6935eb45c51b18b4a60f80b2e88ea9876b4438b0f31586af41c8a4655e44a52&req=fSEmHsx3mYBWFb4f3HP0gDfTm%2FjJG5Zn54bkik123HpLXMBnBUi9%2BH%2Fc85Xt%0AHPOnPxRrAWEJrpu9Yg%3D%3D%0A)

# Editing + Deleting Priorities

1. Click the![](https://downloads.intercomcdn.com/i/o/910888780/681abf51f74be074b2d65046/Screenshot+2023-12-15+at+1.24.20%E2%80%AFPM.png?expires=1784430000&signature=de48a4d82f92c22408b388dc8934e675adb0be75a1104ac7a23e9446361d21da&req=fSEnHsF2molfFb4X1HO4gdzeAjfHjg7DATYTYpihz0e%2FFf3t0gpZdrDmJbnK%0A)on the right of the row of the Priority you wish to edit or delete.
2. Select **edit** or **delete**, depending on what you wish to do.
3. If deleting, you'll be prompted to confirm the action.

   * If the priority is unused, you'll receive the following prompt:

     [![](https://downloads.intercomcdn.com/i/o/910966595/e06b3f8a5a0d72b32beea9e2/Screen+Shot+2023-01-10+at+3.21.17+PM.png?expires=1784333700&signature=9a6811c101d692430be5cfd777fe193bab45b499a079624e490edbeb1fe40703&req=fSEnH894mIhaFb4f3HP0gFv86Tz0Nm3d52xYfvt9TLTrvnKQCzE3yaKAtWJn%0AlnQ%3D%0A)](https://downloads.intercomcdn.com/i/o/910966595/e06b3f8a5a0d72b32beea9e2/Screen+Shot+2023-01-10+at+3.21.17+PM.png?expires=1784333700&signature=9a6811c101d692430be5cfd777fe193bab45b499a079624e490edbeb1fe40703&req=fSEnH894mIhaFb4f3HP0gFv86Tz0Nm3d52xYfvt9TLTrvnKQCzE3yaKAtWJn%0AlnQ%3D%0A)
   * If the Priority is currently associated with one or more tasks, you'll receive a prompt indicating the number of tasks with that Priority and asking you to give those tasks a new Priority.

     [![](https://downloads.intercomcdn.com/i/o/910966937/1c5c4fac4cb48014cc66eb51/Screen+Shot+2023-01-10+at+3.20.52+PM.png?expires=1784333700&signature=7f3b8904dd069f5ea6adb0ff0a87bd0ca696a3075af716c78f653125928e5ff7&req=fSEnH894lIJYFb4f3HP0gGrLjdXJfI0EHbXcUlrhrNhjcxLvF4V39ndXmCOq%0AVNY%3D%0A)](https://downloads.intercomcdn.com/i/o/910966937/1c5c4fac4cb48014cc66eb51/Screen+Shot+2023-01-10+at+3.20.52+PM.png?expires=1784333700&signature=7f3b8904dd069f5ea6adb0ff0a87bd0ca696a3075af716c78f653125928e5ff7&req=fSEnH894lIJYFb4f3HP0gGrLjdXJfI0EHbXcUlrhrNhjcxLvF4V39ndXmCOq%0AVNY%3D%0A)
   * If editing, the Priority edit side sheet will open. Make any changes, and when finished, click **Save** in the top right corner.
