# Overview

⚠️ When using AI voice capabilities in Element451, **your institution is responsible for ensuring compliance with all applicable local, state, and federal laws** related to phone communication and call recording.

Advanced Voice Mode brings Bolt Agents to life with real-time voice conversations across both live chat and phone. Agents can speak with students using natural language, respond in real time, and follow goals that guide the interaction.

Each voice-enabled Bolt Agent is assigned a unique AI voice. Whether a student is chatting in Messenger or talking by phone, the agent uses the same voice for a consistent, personalized experience.

## Key Capabilities

With Advanced Voice Mode enabled, Bolt Agents can:

* Speak with students naturally using real-time voice
* Respond contextually with conversational memory
* Use their voice in [Messenger (Live Chat)](https://help.element451.com/en/articles/6249763-messenger-live-chat) and [Phone Calling](https://help.element451.com/en/articles/8400679-phone-calling)
* Handle **inbound calls** when assigned to a phone number
* Place **outbound calls** [manually](https://help.element451.com/en/articles/8400679-phone-calling) or automatically via [Bolt Jobs](https://help.element451.com/en/articles/11131186-getting-started-with-bolt-agent-jobs)
* Support students 24/7 without staffing limitations
* Be assigned voices in different tones and languages

📌 **Note**: To use Advanced Voice Mode, users should make sure their device has a working microphone and that they have granted Messenger the necessary permissions for Element451 to access it.

# Voice + Messenger (Live Chat)

When enabled, Messenger supports two-way voice conversations between students and Bolt Agents. This voice interaction happens inside the web-based Messenger widget.

## How It Works + Availability

* Voice must be enabled in Messenger Settings (Conversations > Settings > Messenger).
* Students can start speaking instead of typing.
* Bolt Agents reply in voice using their assigned voice profile.
* Conversations happen in real time, with immediate back-and-forth, mirroring a real phone call.

Advanced Voice Mode is accessible wherever the Element451 Messenger is enabled:

* Element451 Pages
* Institution Website with Messenger Embed
* WordPress Messenger Plugin
* StudentHub

## Settings

In [Messenger/Live Chat](https://help.element451.com/en/articles/6249763-messenger-live-chat) Settings, you’ll find three settings specific to voice mode:

1. **Enable Voice Mode**

   * Controls the availability of advanced voice mode in the messenger/live chat channel.
2. **Show Voice Mode Welcome Screen (Optional)**

   * Displays a consent prompt before students start speaking
   * Explains that their voice will be recorded and transcribed
   * Students can choose to continue or cancel to return to text chat

# Configuring Bolt Agents for Voice Mode

You must assign a voice profile to enable a Bolt Agent to be voice-compatible. To do this for an existing agent, follow these steps:

1. Navigate to **Engagement** > **Bolt Agents**.
2. Under the **Agents** section, locate the agent you wish to assign a voice to.
3. Click on the **three vertical dots** ![](https://downloads.intercomcdn.com/i/o/1117700268/72f2e56c3c6b64f6ea4d7e93/More+Icon2.png?expires=1784430000&signature=d459f473b31aee94f7a482e40d925aafb60bc62a80c68044b83ae3c176c76b09&req=dSEmEc5%2BnYNZUfMW3Hu4gZ1qpQl9cnCvHLWgvFoWwRduUQx%2FPXc6U9tuUQ%2FT%0AtA%3D%3D%0A) for that agent and select **Edit**.
4. Locate the **Voice** setting and select one from the list. For more details on selecting a voice, see the [Voice Profile Options](#h_4a739e591b) section below.
5. Click **Save** in the top right corner.

# Troubleshooting

#### Microphone Permission Error

This error occurs when using **Advanced Voice Mode in Messenger** from an external website (not Element451 pages). It primarily affects **Chrome** and **Firefox** users and originates from the website’s **Permissions-Policy header**, which may block microphone access within our <iframe>.

[![](https://downloads.intercomcdn.com/i/o/h9r2yo9x/1580870793/e6f8151185751bb163dee9f55894/ADVM%2BError.png?expires=1784333700&signature=2903c1c39d28cea442b8f075be9ed0739b05c2f064ce063e2e1385818ef79aa8&req=dSUvFsF5nYZWWvMW1HO4zSKRvRy8wAPVm%2B%2FzAKRaUIjH1z3C%2BE2QPOKjjCfW%0Ag9azDf7uq1xNZ0ugeFo%3D%0A)](https://downloads.intercomcdn.com/i/o/h9r2yo9x/1580870793/e6f8151185751bb163dee9f55894/ADVM%2BError.png?expires=1784333700&signature=2903c1c39d28cea442b8f075be9ed0739b05c2f064ce063e2e1385818ef79aa8&req=dSUvFsF5nYZWWvMW1HO4zSKRvRy8wAPVm%2B%2FzAKRaUIjH1z3C%2BE2QPOKjjCfW%0Ag9azDf7uq1xNZ0ugeFo%3D%0A)

**Solution**: To resolve this, update your website’s headers to allow microphone access. This change will enable the browser to recognize and use the microphone within the iframe for Advanced Voice Mode.
