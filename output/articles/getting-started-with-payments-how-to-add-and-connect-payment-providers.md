# Overview

With Element451, collecting payments for event fees, application fees, and deposits is simple and secure. We partner with several trusted payment providers, ensuring modern, safe, and seamless payment processing.

To set up a new payment gateway, you’ll need to select from one of our **Preferred Payment Providers** for the best security. Preferred providers ensure credit card details are not passed through or stored within Element451’s systems.

## Stripe Connect (for Existing Stripe Accounts)

If you already have a Stripe Connect account, you can configure Element451 to work with your existing account. This is done using a webhook.

## Step 1: Create a Stripe Payment Webhook

To complete the integration between Element451 and your Stripe account—and ensure payment statuses are reflected in your Element451 dashboard—you need to configure a webhook in Stripe. This allows Stripe to send real-time updates about payment status changes to Element451.

### Step 1. Log into Stripe

1. Go to your **[Stripe Dashboard](https://dashboard.stripe.com/)**.
2. At the top right, ensure that **Test mode** is **off** (unless you’re testing transactions).

### Step 2: Navigate to Webhooks

1. In the **left sidebar**, click **Developers**.

   * Note: 'Developers' may be at the very bottom of the sidebar.
2. Select **Webhooks**.
3. Click **+ Add endpoint**.

### Step 3: Select Events to Listen To

1. Under **“Select events to listen to,”** expand the **Payment Intent** dropdown.
2. Check the following events:

   * payment\_intent.canceled
   * payment\_intent.payment\_failed
   * payment\_intent.succeeded

### Step 4: Configure the Destination

1. **Destination type**: Select **“Webhook endpoint.”**
2. **Endpoint URL**: Enter the following URL: `https://api.451.io/clients/integrations/stripe/webhook`
3. **Description**: (Optional) Enter Listen for Payment Status changes.
4. **API Version**: Use the latest API version or leave it as default.

Once submitted, you will see the screen below. For new transactions, the payment status will now be reflected accurately in Element451.

## Step 2: Continue Adding Payment Provider in Element451

**After** you have created your webhook, you can continue adding the payment provider gateway in Element451.

* Name (provider name)

  + The **Name** field helps you create unique names for instances where you have multiple gateways with the same provider. For instance, you could name one “Flywire - Alumni Relations.” If you only have one gateway, you can simply name it using the provider’s name, like “Flywire.”
* Description (optional)
* API Secret Key
* API Publishable Key

### To find your API Secret Key + API Publishable Key, follow these steps:

1. Go to **Developers** (from the bottom of the left menu).
2. Click on **API Keys**.
3. You’ll see both the **Publishable Key** and the **Secret Key** (sometimes called the **Private Key**).
4. Click **Reveal live key** (if it’s hidden).

## Touchnet TLink

* Name (provider name)

  + The **Name** field helps you create unique names for instances where you have multiple gateways with the same provider. For instance, you could name one “Flywire - Alumni Relations.” If you only have one gateway, you can simply name it using the provider’s name, like “Flywire.”
* Description (optional)
* Test TLink URL, TLink URL
* Test UPay URL, Test UPay Site ID
* UPay URL, UPay Site ID
* CREDIT\_ACCT\_CODE (optional)

  + The account code Element451 passes to TouchNet with payment requests. This value is visible in the gateway configuration so you can review, update, or remove it when your TouchNet setup changes.

⚠️ **Note:** A stale CREDIT\_ACCT\_CODE can cause payment redirects to fail with a "CREDIT\_ACCT\_CODE contains invalid xml" error, for example after moving to a new TouchNet instance where the old account code is no longer valid. If you update your TouchNet URLs or Site IDs, review this field and clear or update the stored value to match your current TouchNet configuration.

## Flywire Embedded

* Name (provider name)

  + The **Name** field helps you create unique names for instances where you have multiple gateways with the same provider. For instance, you could name one “Flywire - Alumni Relations.” If you only have one gateway, you can simply name it using the provider’s name, like “Flywire.”
* Description (optional)
* Recipient ID (aka Portal Code)

  + This value is assigned by Flywire and can be found in your Flywire dashboard. It connects Element451 to your Flywire account and determines where funds are routed. The format is typically three letters (ABC) or five alphanumeric characters starting with a letter (ABC1D).

# Related Entities

You’ll find a section called **Related Entities** within each payment gateway setup. This section dynamically lists all areas in Element451 where that gateway is actively used.

For example, if you’re using the Flywire gateway to collect payments via a form, the form name will appear here, with a hyperlink, giving you quick access to everything using that gateway.

## Reviewing Related Entities for a Specific Gateway

1. Navigateto your profile picture > **Settings** > **General**.
2. From the lefthand menu, select **Payment Gateways**.
3. Locate the gateway for which you wish to view related entities.
4. Click the **three vertical dots** icon next to the gateway.
5. Select **Edit.**
6. You will then see the Related Entities card for that gateway.

# Testing Gateways

Toggle on **Test Mode** to verify functionality when adding a new payment gateway.

[![](https://downloads.intercomcdn.com/i/o/h9r2yo9x/1259396505/90443fec2882f4dd62d9c82bbbba/Test+Mode+Toggle.png?expires=1784333700&signature=0cd2ba087adfcf6f500b59c45e779e250f98ab81df58a2829a16457b859c0f2c&req=dSIiH8p3m4RfXPMW1HO4zZRZHlGGhgN7tSViP8bO6MN5LZWMaalpbbsltMC0%0Aiqd1taicWlydFAYCcIE%3D%0A)](https://downloads.intercomcdn.com/i/o/h9r2yo9x/1259396505/90443fec2882f4dd62d9c82bbbba/Test+Mode+Toggle.png?expires=1784333700&signature=0cd2ba087adfcf6f500b59c45e779e250f98ab81df58a2829a16457b859c0f2c&req=dSIiH8p3m4RfXPMW1HO4zZRZHlGGhgN7tSViP8bO6MN5LZWMaalpbbsltMC0%0Aiqd1taicWlydFAYCcIE%3D%0A)

In Test Mode, you can use a small test payment (e.g., $1.00) to confirm receipt on the provider’s side.

* Use any payment-enabled module (e.g., applications, forms, events) to test, but we recommend using a test version inaccessible to students or external contacts. For example, create a **test application** to test application fee payments.
* Use a test card number, such as **4242 4242 4242 4242**. Additional test card numbers can be found in [Stripe’s documentation](https://stripe.com/docs/testing).
* No charges will be applied while the gateway is in test mode.
