Introduction to the Mapping Templates Feature

# Overview

Mapping Templates simplify your Import + Export Task workflow by allowing you to quickly apply predefined mapping and transformations to new import and export tasks. These templates come in handy when you find yourself creating similar import and export tasks time and time again.

## Mapping Template Permissions

* **Access Import + Export**: The user has basic access to the import, export, and templates sections.
* **Administer Data Templates**: The user has access to create, edit, and delete import and export templates.
* **Administer Import + Export**: The user has access to create, edit, and delete import and export tasks.

[Learn more about permissions.](https://help.element451.com/en/collections/3963257-permission-permission-groups)

## What Can Mapping Templates Do?

Mapping Templates can reduce time spent meticulously mapping import fields or adding fields to an export. Mapping Templates can provide consistency and go-to report layouts for on the fly report building.

## Features

* Create Custom Templates for Imports and Exports
* View and Edit System Templates for Imports and Exports
* Duplicate Import and Export Templates

## Accessing Mapping Templates

To access **Mapping Templates**, navigate to **Data + Automations > Import + Export > Mapping Templates.**
