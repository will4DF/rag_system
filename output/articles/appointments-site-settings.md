Learn how to configure your Appointments site settings and methods to sharing access to your site and booking pages.

# Overview

The Appointments Site provides a branded, centralized landing page where visitors can easily find and book one-on-one meetings with your institution's staff.

This platform reflects institutional branding through either default or custom domains, functioning as a seamless scheduling entry point. Visitors can browse appointment types, apply filters, and book directly from one location.

# Configuring Appointment Site Settings

If you're an administrator, you have the task of configuring your Appointments Site settings. Here's how:

1. Navigate to **Engagement > Appointments.**
2. Click the **More** icon in the top-right corner.
3. Select **Page Settings.**

Here, you'll find the settings organized into five different cards. We dive into the specifics of each setting below.

## Domains

* **Primary Domain**: Element451 assigns a default domain, such as `elementu.appointment451.sites.451.io`. This cannot be edited.

* **External Domain (Optional)**: While the primary domain URL is functional, it doesn't share the same institutional brand identity and trust as a URL ending in .edu. To that end, you can configure an external domain to mask or hide the primary domain and use a URL ending in your school name or abbreviation (e.g., `appointments.elementu.edu`). You'll likely need to work with your IT or website team for this process. [Read more on configuring external domains here](https://help.element451.com/en/articles/9358702-configuring-external-domains).

# Accessing Your Appointment Site for Booking

Visitors can access your Appointments Site in two primary ways, depending on how your institution is set up:

* **Appointments Site URL**: The direct web address for your Appointments Site (using either the primary or a custom domain). The URL can be customized to guide visitors more intentionally and streamline the booking experience.

* **StudentHub**: If your institution uses StudentHub, students can browse and book appointments directly within the mobile app. Learn more about how the Appointments module is integrated with StudentHub [here](https://help.element451.com/en/articles/9854238-studenthub-features-functionality).

## Customizing the Appointments Site URL

You can customize the Appointments Site experience by adjusting the URL. This helps guide visitors more intentionally, based on what you want them to see, and restricts where they can navigate.

Customization options include:

* **Applying filters** using parameters to pre-select a specific category, appointment type, date range, or duration.

  + *Helpful for streamlining the booking experience.*
* **Hiding filters** using parameters to remove specific filtering options from the left-hand menu, or even collapse the menu entirely.

  + *Helpful for restricting visitors to only the appointment options you want them to view.*
* **Grouping appointments** using a query string parameter to organize the index view by appointment **type** or **category** visually.

  + *Helpful for making the appointment list easier to navigate and understand at a glance.*

Use the collapsible sections below to learn more about each customization:

## Applying Filters Using URL

**The easiest way to create a filtered link is to visit your appointment site, apply the desired filters, and copy the URL**. As you apply filters, the corresponding parameters are automatically added to the address bar—no manual editing needed!

Still, if you prefer to build a link manually, you can. You can apply the following filters by adding query string parameters:

* **category** — Filter by category

  + Example: ?category=Admissions
* **appointment\_type** — Filter by appointment type

  + Example: ?appointment\_type=Walk%20In%20Appointments
* **start** — Filter by start date (or date and time)

  + Example: ?start=2025-04-29T04:00:00.000Z
  + Format: Use ISO format (YYYY-MM-DDTHH:MM:SS.SSSZ)
* **end** — Filter by end date (or date and time)

  + Example: ?end=2025-04-30T03:59:59.999Z
  + Format: Same as start date formatting.
* **duration** — Filter by appointment length (in minutes)

  + Example: ?duration=45
  + Format: Just the number of minutes (no symbols or text).

## Combining Multiple Filters

You can combine multiple filters in the same URL by connecting them with an ampersand (&).

* Example: `https://appointments.elementu.edu?category=Admissions&appointment_type=Walk%20In%20Appointments`

## Necessary Notes

* Add the first filter with a `?`
* Add each additional filter with `&`
* Replace any spaces in values with `%20`
* If a visitor clicks into an individual user’s appointment page after landing on a filtered index page, the filters you applied will automatically carry over—no additional setup needed.

## Hiding Filters Using URL

You can hide filters from the left-hand menu to keep users from changing selections after they land on the page.

Use the same filter names (`category`, `appointment_type`, `start`, `end`, `duration`) when hiding options.

Add `&hide_filters=` to your URL, followed by the filter name(s) you want to hide:

* **Hide *one* filter:**

  + Example: &hide\_filters=category
* **Hide *multiple* filters:**

  + Separate filters with commas.
  + Example: &hide\_filters=category,appointment\_type
* **Hide *all* filters:**

  + Use `all` to collapse the entire filter menu.
  + Example: &hide\_filters=all

## Grouping by Type or Category

You can organize the appointment index page by grouping appointments under labeled sections, based on either their **Type** or **Category**.

**The easiest way to apply grouping is to use the 'group by' dropdown from the left-hand menu. The grouping parameter is automatically added to the address bar—no manual editing needed!**

If you prefer to build a link manually, you can add either `?group_by=type` or `?group_by=category` to your URL.

When applied, the appointment grid on the index page will be split into sections. Each section includes a heading for the Type or Category, followed by the corresponding appointments.

This grouping structure makes it easier for students to browse and identify the right appointment, especially when many options are available.

# Individual + Team Booking Links

## Individual Booking Links

Internal users can also set up a personal booking link by adding a **custom** **slug** in **Appointment Settings > My Settings**.

This feature allows individuals to generate a custom appointment link specific to them and their availabilities. Once set, they can:

* Copy and share their link
* Add it to their email signature
* Create a QR code for business cards, flyers, or office signage
* Share it with students, parents, or external guests

Example of a personal booking link: `appointments.elementu.edu/jordan-smith`

**Note:** This is a self-service feature. Each internal user is responsible for setting their own slug and managing their individual link. [Click here](https://help.element451.com/en/articles/8148396-configuring-your-appointment-availability) to learn how to set your custom slug.

## Team Booking Links

Each team configured in **Appointment** **Settings** > **Team** **Settings** receives a dedicated booking page based on its slug. The URL follows the format: appointments.yourdomain.edu/teams/[team-slug]

* For example, a team with the slug admissions-team would have the booking page: `appointments.elementu.edu/teams/admissions-team`

When a visitor opens a team booking link, they see all of that team's active availabilities with details including duration, location, and availability name.

Team booking links can be:

* Shared via email, chat, or social media
* Used in **Bolt** **Jobs** to send scheduling links to students at scale
* Embedded in campaign communications using scheduling link tokens

For details on configuring teams and how assignment works, see [Team Appointments](https://help.element451.com/en/articles/13921320-team-appointments).
