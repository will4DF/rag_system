The Application Completion Push Pack is a communications campaign that reminds applicants who have started an application at your institution to finish and submit it.

This Pack is for any institution using the [Applications module](https://help.element451.com/en/articles/1963691-getting-started-with-applications).  
​

## Customizations

You must choose an application to associate with this Pack. Once the Pack is installed, you can customize the emails as you see fit. The installed components include your brand assets, such as logos, fonts, colors, and pre-written messaging. Like all Pack components, **we strongly recommend reviewing any materials before activating a workflow**.

**Packs to Support Application Completion, Submission, and Admitted Yield**

This Pack can be used with other Packs in our library to support the full application journey from submission to deposit.

* [Application Submit Push: Encourages applicants to submit a completed application.](https://help.element451.com/en/articles/6887554-application-submit-push)
* [Admitted Yield Campaign: Encourages admitted students to submit their deposit and commit to attending your institution.](https://help.element451.com/en/articles/6887556-admitted-yield-campaign)

See how you can use these Packs together in the overview video in the section above.

## Pack Install Options

* **Application Type**: You can install this Pack multiple times to connect to as many applications as you wish. However, each Pack install only connects to **one single application**. Select the application you wish you use with this Pack in the drop-down menu.
* **Configure Communications**

  + **Sender email address and name**: configures the reply-to email address and the name of the sender.
  + **SMS phone number and sender name**: similarly configures the phone number and name referenced in text messages that go out. *(e.g., "This is Chris from Element University...")*
  + **Contact info**: Populates the footer fields in the associated emails.

## Email Components

The emails included with this campaign come with short reminders to encourage applicants to return to their portal to complete the application.

This also includes the following tokens:

* [user:first\_name, fallback="there"]

  + Displays the user's first name with a fallback option in the event it isn't in the system (unlikely).
* [client:name]

  + Displays your institution's name as specified in your Pack tokens.

Feel free to edit the messages as you see fit or add any additional information or context for the recipient about the next steps in this process.

## Workflow Components

The installed workflow is available under **Data + Automations** > **Workflows** > **All** **Workflows**.

[![](https://downloads.intercomcdn.com/i/o/651331733/06a6beee01d60d88c49a13df/workflow_gif.gif?expires=1784333700&signature=611e956519927e0cae2a1f325538ab1a673910bd61e06c962ef5cf03a4ebe456&req=ciUmFcp%2FmoJcFb4f3HP0gDTbvaB71%2FhprY1W8317FJupug8qbUoiBORuP1TY%0AW%2BIPPkiVScbdNn777g%3D%3D%0A)](https://downloads.intercomcdn.com/i/o/651331733/06a6beee01d60d88c49a13df/workflow_gif.gif?expires=1784333700&signature=611e956519927e0cae2a1f325538ab1a673910bd61e06c962ef5cf03a4ebe456&req=ciUmFcp%2FmoJcFb4f3HP0gDTbvaB71%2FhprY1W8317FJupug8qbUoiBORuP1TY%0AW%2BIPPkiVScbdNn777g%3D%3D%0A)

This will automate the campaign. Each step in the workflow will look to see if the user has started but not completed an application using the following segment filter.

* Application > All Properties

  + {Type} is {Application picked in Pack install options}
  + {Status} is {Started}

Before activating the campaign, check the delay in between steps to confirm the campaign will run at your desired message frequency.
