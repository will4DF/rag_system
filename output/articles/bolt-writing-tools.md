# Overview

Bolt Writing Tools, powered by the Copywriter Agent, streamline your writing and editing tasks in the Campaigns, Conversations, and Pages modules. They can generate conversation replies based on context or user prompts, making drafting and editing a breeze. With features like improving writing, correcting spelling and grammar, shortening or expanding text, changing tone, and translating, these tools handle the heavy lifting. They also summarize conversations into shareable notes. Bolt Writing Tools save you time by automating repetitive communication and writing tasks.

# Composing New Conversations + Replies

When replying to a Conversation, you can describe the intent of your message, and the Copywriter Agent will generate a customized email or SMS message.

![](https://downloads.intercomcdn.com/i/o/1093333732/9db3eda54cd61aefa4a9642e/Note.png?expires=1784430000&signature=426fd73bcdc1e841617228f0a24091bc218a740abcda3a2b941241976b572109&req=dSAuFcp9noZcW%2FMW3Hu4gQ6D%2BHIcR183psxiSPijplw%2BkmMsvee6lMyvZKkc%0AEg%3D%3D%0A) The Copywriter Agent will optimize the reply based on the channel (e.g., SMS responses will be around 160 characters, and e-mail responses will contain greetings).

## New Conversations

1. When starting a conversation, click the **Generate Custom Reply** icon.

2. Describe the message you want the Copywriter Agent to generate in everyday language.
3. Click the **check mark icon** to send your prompt to the agent.
4. Review the message generated by the agent.

   1. If you're satisfied, you can send the message.
   2. If you want to make edits yourself, edit the message as you wish, and once satisfied, send the message.
   3. If you want the agent to try again, repeat the process starting with step 1.
5. If you are sending an email, you can also use the agent to generate a subject line using the context of the message. On the subject line field, click the Bolt icon, and the text will automatically generate. If you want the agent to try again, click the Bolt button again.

## Replies

When replying to a conversation, click the **Draft Reply** icon. You will be presented with two options: **Auto-Generate Reply** and **Generate Custom Reply**.

## Auto-Generate Reply (No Prompt)

If you want the Copywriter Agent to review the conversation history and use context to generate a reply automatically, use this option.

1. Click the **Auto-Generate Reply** button.
2. Review the message generated by the agent .
3. Edit if needed, and when satisfied, click **send**.

## Generate Custom Reply (Prompt)

If you want to use a prompt and explain to the Copywriter Agent how you want to reply, use this option.

1. Click the **Generate Custom Reply** button.
2. Describe the message you want to the agent to generate in everyday language.
3. Click the **check mark icon** to send your prompt to the agent.
4. Review the message generated by the agent.

   1. If you're satisfied, you can send the message.
   2. If you want to make edits yourself, edit the message as you wish, and once satisfied, send the message.
   3. If you want the agent to try again, repeat the process starting with step 1.

# Editing and Translating Content + Replies

Bolt offers writing tools that allow you to edit your text content in Campaigns, Conversations, and Pages. You can use these tools to:

* Improve Writing
* Fix Spelling + Grammar
* Make Shorter
* Expand
* Change Tone
* Translate

## Editing + Translating

1. Type your message.
2. Highlight the text.
3. Select the **Bolt** icon.
4. Select what you would like the Copywriter Agent to do for you:

   * Improve Writing
   * Fix Spelling & Grammar
   * Make Shorter
   * Expand
   * Change Tone
   * Translate

# Summarizing a Conversation

Instead of manually summarizing and writing notes after a conversation, use Bolt via the Copywriter Agent to generate a summary for you. This feature is perfect for sharing conversation summaries and providing context to your team members.

## Summarizing a Conversation

1. When you're in a conversation, toggle to **Note.**
2. Click theorange **Bolt icon**.
3. Click **Summarize Conversation**.
4. Click "**Add Private Note**" when you are ready to save the note.
