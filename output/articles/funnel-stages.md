# Overview of Funnel Stages

Element451's funnel stage filter is a versatile segment builder that enables you to create a segment based on a specific stage of the higher education funnel. For instance, you can easily generate a list of individuals who have submitted an application or all those who have submitted a deposit. The funnel stages are determined based on the milestones of each user, and we've listed the definitions of each funnel stage below. Funnel stages are highly effective segment builders that can be utilized for exports, rules, and more.

***📙 Note:*** *We recommend familiarizing yourself with [segments](https://help.element451.com/en/collections/124536-people#segments) and [milestones](https://help.element451.com/en/articles/3419189-milestones-an-overview) before working with funnel stages.*

# List of Funnel Stages

The stages of the funnel and their associated milestones are as follows. For a list of milestone types in order, [please refer to this resource](https://help.element451.com/en/articles/3419189-milestones-an-overview).

|  |  |  |
| --- | --- | --- |
| Funnel Stage | Description | Milestone Type |
| **Suspect** | The student has created a user profile, but does not have any of the further stage milestones | Created Date |
| **Prospect** | The student has a “Date of Inquiry” milestone, but has not yet started an application. | Date of Inquiry |
| **Application in Progress** | The student has started an application (or completed all required fields and therefore completed the application), but has not yet submitted it | Application Start Date Application Complete Date |
| **Application Submitted** | The student has submitted an application but is not yet on Hold or has not reached a decision milestone (Denied, Waitlist, Conditional Admit) | Application Submit Date |
| **On Hold** | The student is on hold but has not reached a further stage milestone (Denied, Waitlist, Conditional Admit) | On Hold |
| **Denied** | The student has been denied admission | Deny Date |
| **Waitlisted** | The student has been put on the waitlist for admission | Waitlist Date |
| **Admitted** | The student has been given an offer of admission | Admitted Date |
| **Conditional Admit** | The student has been given a conditional offer of admission | Conditional Admitted Date |
| **Deferred** | The student has been admitted, but they have chosen to defer enrollment | Defer Date |
| **Withdrawn** | The student has been admitted, but they have chosen to withdraw | Withdrawn Date |
| **Deposits** | The student has submitted a deposit but has not yet enrolled | Deposited Date |
| **Enrolled** | The student has enrolled and reached the final funnel stage | Enrolled Date |

Journeys is also listed as a Funnel filter because of its usefulness in tracking custom funnels. [Learn more about Journeys](https://help.element451.com/en/articles/6825003-journeys).

# Using the Funnel Stage Filter

📙 **Note**: Students who've progressed beyond certain stages won't appear in earlier funnel stage filters. For instance, if a student has the **enrolled** milestone, they will not be included using the ***Funnel Stage > Admits*** filter.

Now we’ll walk you through an example of how to use the funnel stage filter. To get started, navigate to **Contacts** > **People**.

1. Click **Add Filter** and search for the Funnel Stage filters.

   [![](https://downloads.intercomcdn.com/i/o/897247405/ce41c44f7454bc97e0e30b41/People+-+Funnel+Stages+-+Add+Filter.png?expires=1784333700&signature=997bf5b1bbee4793f26ff1b6cf0854f7237f618fa40362cdfbe1280595820ae5&req=fCkgFM15mYFaFb4f3HP0gJ7I2G%2FvdWxRFm32DQ0u4j14498sjH3On5x5P4iL%0Ad%2BY%3D%0A)](https://downloads.intercomcdn.com/i/o/897247405/ce41c44f7454bc97e0e30b41/People+-+Funnel+Stages+-+Add+Filter.png?expires=1784333700&signature=997bf5b1bbee4793f26ff1b6cf0854f7237f618fa40362cdfbe1280595820ae5&req=fCkgFM15mYFaFb4f3HP0gJ7I2G%2FvdWxRFm32DQ0u4j14498sjH3On5x5P4iL%0Ad%2BY%3D%0A)
2. Click on the filter you wish to use. For this example, we will use **Applicants Submitted**.

   [![](https://downloads.intercomcdn.com/i/o/897247843/132fad662f68f4c026f7331d/People+-+Funnel+Stage+-+Applicants+Submitted+.png?expires=1784333700&signature=5d0fd4c492a4fd0ec462f9fd4b9022fc3730b52a5972c800c58572b74b8f7204&req=fCkgFM15lYVcFb4f3HP0gM%2BzrcF4i2JpAZ6jvjEIJpnZvLy6xi7DdA3reNx6%0ADCg%3D%0A)](https://downloads.intercomcdn.com/i/o/897247843/132fad662f68f4c026f7331d/People+-+Funnel+Stage+-+Applicants+Submitted+.png?expires=1784333700&signature=5d0fd4c492a4fd0ec462f9fd4b9022fc3730b52a5972c800c58572b74b8f7204&req=fCkgFM15lYVcFb4f3HP0gM%2BzrcF4i2JpAZ6jvjEIJpnZvLy6xi7DdA3reNx6%0ADCg%3D%0A)
3. After selecting the filter type, you will be prompted to determine its properties. Each filter type has unique properties. In our example (Applicants Submitted), you can use the **Add** **Property** option to select application major, application student type, application term, application type, country, intended student type, milestones application, milestones major, milestones student type, milestones term, or state. You can add multiple properties to narrow down your data further. Additionally, you can add a Date Property like the application submission date.

   [![](https://downloads.intercomcdn.com/i/o/897251380/255ba2dd6d6fc4a34d89207a/People+-+Funnel+Stage+-+Property.png?expires=1784333700&signature=1555f98741718e0ea935c09883f9e6d530f54b699160bd091c08830fb622fc46&req=fCkgFMx%2FnolfFb4f3HP0gGvN2lxun76ArFMUljpkrKMuRhYsmWifpmIehKAD%0A4LM%3D%0A)](https://downloads.intercomcdn.com/i/o/897251380/255ba2dd6d6fc4a34d89207a/People+-+Funnel+Stage+-+Property.png?expires=1784333700&signature=1555f98741718e0ea935c09883f9e6d530f54b699160bd091c08830fb622fc46&req=fCkgFMx%2FnolfFb4f3HP0gGvN2lxun76ArFMUljpkrKMuRhYsmWifpmIehKAD%0A4LM%3D%0A)
4. Click **Submit,** and you will see a list of all the people who meet the criteria of your filter. You can then save that list as a new segment using the **Save As New Segment** button.

*💡 **Pro tip**: By using funnel stage properties, you can easily combine your funnel stage segments with other properties like term, major, and student type.*
