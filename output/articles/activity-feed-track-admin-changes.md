Element451 tracks changes performed by internal users, allowing for greater transparency among colleagues.

# Overview

The activity feed includes tracked changes made by internal users. As a result, if needed, leadership or admins can quickly investigate changes in a student's record.

---

# Changes Tracked

The activity feed includes the following changes performed by an internal user:

|  |  |
| --- | --- |
| **Module** | **Activity Tracked** |
| Appointments | Appointments scheduled  Appointments canceled |
| Conversations | Added participant  Update of assignment  Closed  Updated favorite  Joined  Left  Open  Updated tag |
| Decisions | Checklist item added  Checklist item removed  Checklist item updated  Criteria deleted  Criteria updated  Update of assignment  Note added  Note deleted  Note updated  Decision released  Stage updated  Status updated |
| Event | Marked as attended |
| Phone | Call completed  Call not answered |
| Tasks | Assigned  Created  Deleted |
| Users | Merged  Deleted  Updated name  Updated address  Updated milestone  Updated profile  Updated email address |
| Other | External activity completed |

# Viewing Tracked Changes

![](https://downloads.intercomcdn.com/i/o/1097028669/9e9494b2addae2dfc87aa68b/Note.png?expires=1784430000&signature=10bbcdb4ce710bb7ec4cf7380ec64a25a3e7bedc45fd8079c7fd19c08b589f06&req=dSAuEcl8lYdZUPMW3Hu4gT5yTfcQPLsadv4WWS7oadk%2BO%2BZALsX%2FSWYsBRXf%0ASw%3D%3D%0A) The Activity card must be enabled for your profile template. [If you want more information on profile templates, visit this article](https://help.element451.com/en/articles/6449965-bolt-profile-templates).

1. Navigate to **Contacts** > **People** or use the search bar in the top right corner to search the student's name.
2. Click on their name to open the profile.
3. Look for the **Activity** card on the user profile. You can also search for it using the search bar.

   [![](https://downloads.intercomcdn.com/i/o/897705805/eeeb2847c16f0f53a712327d/Activity+Feed+Profile.png?expires=1784333700&signature=62a4ee3746313208375ad8559f4edd7b045d6346a08caa5e3ac785dbaf09d38b&req=fCkgEcl7lYFaFb4f3HP0gPnIALHHEKXtOZi6h8GyKl%2BK2pppeDHmRNEnzJuk%0AElA%3D%0A)](https://downloads.intercomcdn.com/i/o/897705805/eeeb2847c16f0f53a712327d/Activity+Feed+Profile.png?expires=1784333700&signature=62a4ee3746313208375ad8559f4edd7b045d6346a08caa5e3ac785dbaf09d38b&req=fCkgEcl7lYFaFb4f3HP0gPnIALHHEKXtOZi6h8GyKl%2BK2pppeDHmRNEnzJuk%0AElA%3D%0A)
4. To expand the information, click the **arrow** next to Activity or click the **More** button.
5. When an internal user makes one of the above-mentioned changes, it will show on the student's activity feed as follows:

   [![](https://downloads.intercomcdn.com/i/o/662423127/e35b9ab83d6993eedcfe0fdc/activity_feed2.png?expires=1784333700&signature=ef4e963a9d8b812744c3c0dba64a9a2c1552c394614161e4e732a5b983db1fcd&req=ciYlEst9nINYFb4f3HP0gLSRtUE6zCs1BChlNbZ28OhrYdzDX0vQq7d%2BazF9%0AouU%3D%0A)](https://downloads.intercomcdn.com/i/o/662423127/e35b9ab83d6993eedcfe0fdc/activity_feed2.png?expires=1784333700&signature=ef4e963a9d8b812744c3c0dba64a9a2c1552c394614161e4e732a5b983db1fcd&req=ciYlEst9nINYFb4f3HP0gLSRtUE6zCs1BChlNbZ28OhrYdzDX0vQq7d%2BazF9%0AouU%3D%0A)

   This internal user activity tracking allows for greater transparency in changes made by internal users, allowing for easier management of tasks and workflows in an office.

For a list of tracked student activity changes, please see [Activity Feed: Overview](https://help.element451.com/en/articles/5159877-activity-feed-overview).
