Learn how to use the Appointments Dashboard in Insights to analyze and refine your appointment metrics effectively.

# Overview

The Appointments dashboard analyzes the performance of all Appointments metrics. Explore performance metrics by date, segment, and various student dimensions.

## Accessing the Dashboard

The Appointments dashboard can be found via the Insights sub-menu. The Insights module can be accessed from the Data + Automations dropdown in the top navigation.

---

# **Dashboard Features**

The Appointments dashboard displays period-over-period comparisons, monthly changes in appointment performance rates, and a wide variety of performance measurements.

**Global Controls**

The Appointments dashboard can be filtered and controlled in several ways. Find the global controls at the top of each tab. These global controls affect each tab. Filters applied on one tab will carry over to the others.

Global controls feature filters for **segment, major, student type,** and **term.** Select one or many from most control categories and one segment at a time.

**Segment Filters**

The Appointments report can only be filtered by certain dimensions by default. The segment filter is a great way to filter the report by dimensions that matter to you. Create a segment in the People module, and set it as a calculated segment.

Please allow 24 hours for new calculated segments to appear and filter correctly in Insights.

More on using [segments and Insights](https://help.element451.com/en/articles/6798155-using-segments-in-insights) together.

# **Tabs**

Data on the Appointments dashboard is organized by date as well as various dimensions selected in the controls menu.

## Overview Tab

***Visualizations***

* *Highlights*

  + Period-over-period performance of appointments.
  + Filtered totals and changes in metric rates for appointments scheduled, appointments attended, appointments canceled, appointments overdue, and appointment attendance rates.

* *Top performers*

  + Top three appointment types by scheduled appointments.
  + Top three availabilities by scheduled appointments
  + Top three appointment types by appointment attendance.
  + Top three teams by appointment attendance.
  + Top three appointment types by attendance rates.

* *Days between*

  + A breakdown of the days between scheduling the appointment and the appointment date itself, by appointment type.
* *Performance over time*

  + Select your own metric for analysis (scheduled, attended, canceled, no show).
  + Appointments by appointment date.
  + Appointments by appointment type and date.

## Explorer Tab

***Unique Controls***

* Funnel Stage: choose whether you want to view appointment metrics by a particular funnel stage.
* Appointment Identifier: choose whether you want to view metrics by appointment name or type.
* Dimension: choose whether you want to break down metrics by term, major, student type, or state.

***Visualizations***

* *Funnel*

  + Breakdown of all available metrics by location, type, availability, and date*.*

* *Appointment log*

  + View all available metrics by selected identifier, dimension, and up to three funnel stages.

# **Metric Glossary**

|  |  |
| --- | --- |
| **Metric** | **Definition** |
| Appointments scheduled | Total appointments that have been scheduled for the date range selected. |
| Appointments attended | Total appointments that have been attended for the date range selected. |
| Appointments canceled | Total appointments that have been canceled for the date range selected. |
| Appointments no show | Total appointments that have been labeled as a "no show" for the date range selected. |
| Appointments overdue | Total appointments that have been scheduled, but the appointment date has come and gone without an update to attended, canceled, or no show. |
| Total Appointment Duration | The total time scheduled for appointments. |
| Attendance rate | The percentage of appointments that are attended that have been scheduled. |
| Canceled rate | The percentage of appointments that are canceled that have been scheduled. |
| No show rate | The percentage of appointments that are a no show that have been scheduled. |

# **Troubleshooting & FAQ**

* ### Why is there no data?

  There are a variety of reasons an Insights report is blank. Try the following quick fixes:  
  ​

  + **Reset the report.** Visualizations may be filtering the report. Check the date controls. If the date is too far in the past, it may pre-date your activity in Element451.
  + **Check** what fields are being used.
  + If data is still missing, there may be issues with your data in Element. Check out [this guide](https://help.element451.com/en/articles/4404458-a-guide-for-data-clean-up) for **data cleanup.**
* ### **How often does the Appointments dashboard update?**

  The Appointments dashboard currently refreshes once a day at 12:00 am Eastern.
