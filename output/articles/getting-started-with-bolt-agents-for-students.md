# Overview

Bolt Agents are the ultimate team members. These personalized digital agents use [BoltAI](https://help.element451.com/en/articles/11061870-getting-started-with-bolt-ai) to provide tailored responses to specific objectives. Designed to support students, each agent is trained to handle specific roles and tasks.

## Key Features

* **Element451 Integration:** Through deep CRM integration, agents can tailor conversations and actions to individual student needs.
* **Knowledge Hub:** Utilizes your specific information to provide accurate responses.
* **Customizable Interface:** You have extensive customization options featuring a modern, adaptable UI to fit your institution’s unique requirements and ensure a superior user experience.
* Agent Types: Choose from package-dependent templates that provide built-in skills and starting instructions for common student-support roles. Review Onboarding + Managing Bolt Agents for Students for the current options available in the product.
* **Teams:** Create groups of agents to control their activity using condition filters for Page URL, Path URL, UTM Parameters, and Conversation Channel.
* Built-in Skills and Permissions: Enable system skills such as starting applications or registering for events, then scope their access through agent permissions. Custom Skills are institution-authored triggers and actions that are created at the instance level and enabled separately on each agent.
* **Personalization Options:** You can set custom titles, greetings, avatars (uploaded or AI-generated), and conversation starters for each agent.
* **Knowledge Hub Access:** Define the level of access each agent has to the Knowledge Hub.
* **Real-life Interaction Model:** Designed to emulate real-life interactions where specialists handle specific queries, enhancing the personal feel of support.
* **Multilingual Support:** Agents can communicate effectively in multiple languages, breaking down language barriers.
* **Multichannel Capability:** For consistent support across platforms, agents can be enabled via live chat, SMS, email, and WhatsApp.

# Built-in Agent Skills

You can enable the built-in system skills below per agent to support standard tasks. Built-in system skills and institution-authored Custom Skills are configured separately; review Custom Skills for Bolt Agents for institution-specific behavior.

|  |  |
| --- | --- |
| **Start an Application** | Guides students step-by-step through starting and completing applications. |
| **Get Application Status** | Retrieves and updates students on their application progress. |
| **Application Status Checklist** | Retrieves and updates students on their checklist items. |
| **Register for Event** | Assists with the event registration process. |
| **Common App Knowledge** | Utilizes the Common App website for comprehensive application support. |
| **Financial App Knowledge** | Source information from FinancialAid.gov to help with financial application queries. |
| **Handoff** | Transfers to a human agent when more personalized support is needed. |
| **Appointment Scheduling** | Helps students schedule appointments, ensuring they receive the help they need promptly. |

| **User Data Access** | Enables agents to access and share student record data stored in custom fields. |

# How are Bolt Agents Different from Live Chat?

Bolt Agents and Live Chat each play a unique role within the Conversations Module, yet they also complement each other to provide comprehensive support. Here’s how they differ and collaborate:

* **Live Chat**: Serves as a direct communication channel within the Conversations Module, enabling real-time conversations between students and support agents during set hours. It’s one piece of a larger support ecosystem.

* **Bolt Agents**: While Live Chat facilitates human interaction, Bolt Agents can autonomously manage chat sessions, providing immediate responses and support. Depending on your configuration, they can operate independently or alongside human agents. This versatility ensures that support is available around the clock, blending the efficiency of AI with the personal touch of human support.

# Additional Features

## Handoff Capabilities

Bolt Agents can seamlessly transfer unresolved inquiries to human agents, ensuring that complex issues receive attention. [Click here to learn more about handoffs](https://help.element451.com/en/articles/8993398-bolt-agent-handoffs).

## Customizable Visibility

You can use conditions to specify where Bolt Agents and Live Chat appear on your site. For example, you can disable agents on financial aid pages while keeping the live chat widget active, ensuring tailored support experiences.

## Conversation Starters

Integrating [Live Chat Conversation Starters](https://help.element451.com/en/articles/6249763-messenger-live-chat#h_df32db7601) with the [Inquiry Flow Skill](https://help.element451.com/en/articles/8993380-bolt-agent-skills) can significantly increase student inquiries by engaging them in relevant contexts and encouraging meaningful interactions.
