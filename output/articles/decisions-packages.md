Learn to create and manage letters and financial aid awards with the Packages feature, enhancing student communication.

# Overview

The Packages feature is a powerful tool for configuring acceptance and financial aid letters. With this feature, you can create customized letters based on the decision status and apply them to specific applications, giving you complete control over your communication process.

## Accessing Packages

1. Navigate to **Applications** > **Decisions** > **Decision** **Settings.**
2. Click on the **Packages** tab.

# Package Items

Package Items—**Letters**, **Financial** **Awards,** and **Other** allows you to push acceptance letters and financial aid award information to a student's Application Site/Portal, StudentHub, and Microsite. See above for more details on where they appear within each feature. Below we explain each Package Item in more detail.  
​

## Letters

Package Letters can be used for various purposes, primarily for acceptance and financial aid-related letters. Also, you can have multiple letters that work with a particular application.

### How To: Create a New Letter

#### Step 1: Create a New letter

1. Navigate to **Applications** > **Decisions** > **Decision** **Settings.**
2. Click on the **Package** tab.
3. Confirm **Letters** is selected from the list of Package Items on the left-hand panel.
4. Click on the **circle** **plus** **sign** button

   [![](https://downloads.intercomcdn.com/i/o/1032971432/19da990f8326d0b11e4d2f29/%2B+Plus+Button+Transparent.png?expires=1784333700&signature=68968f5525d231dceb825388478eb5f8164ad1007f6a2ef171574b973e7a0afa&req=dSAkFMB5nIVcW%2FMW1HO4zUyX5JtJGsf5hioHuls2MPqtlDvjARO3Ja4Jc8yi%0Axxf8%0A)](https://downloads.intercomcdn.com/i/o/1032971432/19da990f8326d0b11e4d2f29/%2B+Plus+Button+Transparent.png?expires=1784333700&signature=68968f5525d231dceb825388478eb5f8164ad1007f6a2ef171574b973e7a0afa&req=dSAkFMB5nIVcW%2FMW1HO4zUyX5JtJGsf5hioHuls2MPqtlDvjARO3Ja4Jc8yi%0Axxf8%0A)

   in the bottom right corner of the screen.
5. Configure the settings in the New Letter dialogue window:

   * **General** Tab

     + **Active**: Enables the letter to be used on decisions.
     + **Title**: Name your letter. This name is visible to students in the Microsite.
     + **Status**: Use the dropdown to select which status the letter should apply to. Note: The decision must be in this status for the letter to populate in the decision.
   * **Works For** Tab: Select the application(s) you wish this letter to work with.
6. Click **Add.**

[![](https://downloads.intercomcdn.com/i/o/1030403571/8cf8ec7cb82975f957172095/Important+-+Orng.png?expires=1784333700&signature=ecc3b76b6cdf96cd5638182876cb31a5559bbde72e5f5c0d580c8680824c339f&req=dSAkFs1%2BnoRYWPMW1HO4zV6F2pg2LSNg03p7YwRbNCt4ZIUAyrrzEmkfETS8%0ACvDXA3vpJVDext3ERtE%3D%0A)](https://downloads.intercomcdn.com/i/o/1030403571/8cf8ec7cb82975f957172095/Important+-+Orng.png?expires=1784333700&signature=ecc3b76b6cdf96cd5638182876cb31a5559bbde72e5f5c0d580c8680824c339f&req=dSAkFs1%2BnoRYWPMW1HO4zV6F2pg2LSNg03p7YwRbNCt4ZIUAyrrzEmkfETS8%0ACvDXA3vpJVDext3ERtE%3D%0A)

Letters are not automatically sent to a student's microsite when their decision status matches the status configured for the letter. Once a decision reaches a status that matches one specified within a letter and the application meets any other set conditions, the letter will appear in the decision under the Packages tab. However, you must manually activate it to send, or you can configure an Intelligent Admissions rule to automate the sending process. More details are provided at the end of this article.

#### Step 2: Add Conditions and Content

1. Locate your new letter in the list and click the **three** **vertical** **dots**.
2. Select **View**.
3. Configure the Conditions and Content for your letter:

   Under the Conditions tab, you can build out conditions to create different versions of your letter if you choose. For example, if the Dean signs the acceptance letter, you can create versions for each college/department. This is facilitated through conditions. You'll need to add all of your conditions first to build the different versions of your letter in the next step.

   If you have only one version of your letter, you can skip this step and proceed to the **Content** tab.   
   ​

Once you are done, you can close out. The changes are saved automatically. Note: You can add multiple conditions to a version.
   * If you wish to add another version, repeat the process by clicking the **circle plus sign button**

### How To: Preview, Print, + Activate for Student Viewing

#### Preview and Print Letters:

1. Navigate to **Applications** > **Decisions** > **All Decisions.**
2. Locate and open the Decision where you want to preview and activate a letter.
3. Click on the **Package** tab.
4. Click **Letters** on the left-hand panel.
5. Click the **eye** icon next to the letter you wish to preview/print.
6. A preview will open. From there, you have the option to **print**.

#### Activate/Send the Letter for Student Viewing:

1. Navigate to **Applications** > **Decisions** > **All Decisions.**
2. Locate and open the Decision where you want to preview and activate a letter.
3. Click on the **Package** tab.
4. Click **Letters** on the left-hand panel.
5. Locate the letter you wish to send.
6. Switch the **Active to Send** toggle to **Yes**. This will **automatically** push the letter to the Application Site/Portal and StudentHub. If you want them to also appear in a Microsite, you must have the Acceptance Package section enabled on that microsite. This process is covered in [Microsites Part 3: Content Block and Section Descriptions](https://help.element451.com/en/articles/8576832-microsites-part-3-content-block-and-section-descriptions#h_3c9d1d79ac).

#### Activate/Send the Letter (Intelligent Admissions):

You can streamline your workflow by automating the activation of decision letters using an AI rule with the "Enable Package" action.

[Learn more about Intelligent Admissions rules →](https://help.element451.com/en/articles/9241624-intelligent-admissions-decision-rules-automation)

4. Click on the **circle** **plus** **sign** **button**

   [![](https://downloads.intercomcdn.com/i/o/1032971432/19da990f8326d0b11e4d2f29/%2B+Plus+Button+Transparent.png?expires=1784333700&signature=68968f5525d231dceb825388478eb5f8164ad1007f6a2ef171574b973e7a0afa&req=dSAkFMB5nIVcW%2FMW1HO4zUyX5JtJGsf5hioHuls2MPqtlDvjARO3Ja4Jc8yi%0Axxf8%0A)](https://downloads.intercomcdn.com/i/o/1032971432/19da990f8326d0b11e4d2f29/%2B+Plus+Button+Transparent.png?expires=1784333700&signature=68968f5525d231dceb825388478eb5f8164ad1007f6a2ef171574b973e7a0afa&req=dSAkFMB5nIVcW%2FMW1HO4zUyX5JtJGsf5hioHuls2MPqtlDvjARO3Ja4Jc8yi%0Axxf8%0A)

# Tokens

Enhance the personalization of your letters by adding tokens. There are two types of tokens: **Global** and **Custom**. Custom Tokens in Decisions are unique—they don't pull data directly from student records. Instead, create token placeholders in Decision Settings first. Then, values will be assigned to these tokens at the application decision level for tailored letter personalization.

[![](https://downloads.intercomcdn.com/i/o/1032986686/0adfbed37405fb24a92f12fd/Note_Orange.png?expires=1784333700&signature=19a55b0f1cab064f04dc0baeda4361dbf24e68ccb350c85fde75373127eca648&req=dSAkFMB2m4dXX%2FMW1HO4zQZT1HDCdNuma4CkLGD5kANKkjJgLXE31PK6pcg6%0Amg3CyobOaYMgWimAWKU%3D%0A)](https://downloads.intercomcdn.com/i/o/1032986686/0adfbed37405fb24a92f12fd/Note_Orange.png?expires=1784333700&signature=19a55b0f1cab064f04dc0baeda4361dbf24e68ccb350c85fde75373127eca648&req=dSAkFMB2m4dXX%2FMW1HO4zQZT1HDCdNuma4CkLGD5kANKkjJgLXE31PK6pcg6%0Amg3CyobOaYMgWimAWKU%3D%0A)

Custom data field tokens cannot be used in package letters.

Below, we’ll guide you step-by-step through this process:

### How To: Add Tokens to Letters

Tokens are inserted using the content editor; manually typing tokens in Decision Letters is not supported. Here's how:

1. Follow the same process for [Creating a Letter](#h_c295b56677) outlined earlier in this article.
2. Click anywhere in the letter to launch the formatting toolbar.
3. Click the token icon.

   [![](https://downloads.intercomcdn.com/i/o/1033887297/0f73d1b457182f6b5fe63252/Decisions+-+Letters+-+Insert+Token.png?expires=1784333700&signature=71a4df588c6b244c3b25a33562cd716fd5f6c25ab16fefab20c5b15216eb8ee4&req=dSAkFcF2moNWXvMW1HO4zb%2Bdy9Te5s%2Bg2dF%2FcY24ROzxkDdf2bUAZ4%2B1Ed1n%0ASw2R%0A)](https://downloads.intercomcdn.com/i/o/1033887297/0f73d1b457182f6b5fe63252/Decisions+-+Letters+-+Insert+Token.png?expires=1784333700&signature=71a4df588c6b244c3b25a33562cd716fd5f6c25ab16fefab20c5b15216eb8ee4&req=dSAkFcF2moNWXvMW1HO4zb%2Bdy9Te5s%2Bg2dF%2FcY24ROzxkDdf2bUAZ4%2B1Ed1n%0ASw2R%0A)
4. The token modal will open, allowing you to select a token. It has two tabs: Global and Custom.

   * **Global** tokens are the system data fields we support adding to your letter. We do not support adding other system tokens not listed here (including your custom data field tokens). The student's **Intended School** is available as a Global token, which is helpful when the program major is broad (for example, Liberal Arts) but you want to display the student's selected intended school or interest area.
   * **Custom** tokens are the token placeholders added in Decision Settings and then assigned a value at the decision level. Those two processes are outlined in the forthcoming section.

### How to: Preview Tokens in Letters

The best way to preview how your letter looks with token values added, is to preview a letter on a specific decision.

1. **Open a decision** from an application that uses the letter you want to preview. Ensure the decision's status matches the configured status for the letter.
2. Navigate to the **Package** Tab.
3. Select **Letters** from the left-hand menu.
4. Click the **eye** **icon** next to the desired letter to view the preview. The tokens will automatically fill with the relevant data for that student and decision.

**What happens if there is no data for the token to pull?**  
​*Let's say you have a token for a middle name, **[user:middle\_name]**, but the student didn't enter a middle name. The space will be empty because there is no data to use. Therefore, we advise that you mindfully include tokens that have data.*

# Alternative Ways to Send Decision Letters

In addition to activating letters to be visible in the Application Site, StudentHub, and Microsite, you can also set up a **Campaign** and **Workflow** to send out letters. Here’s how you could do this:

1. **[Create Your Campaign](https://help.element451.com/en/articles/1513676-create-a-campaign-email)**: Design your acceptance letter as an ongoing Campaign.
2. **[Set Up a Workflow](https://help.element451.com/en/articles/1500282-how-to-create-a-workflow)**: Use the trigger 'Decision Stage Changed = Release' to initiate the sending of the Campaign. The action should be 'Send Communications.'
