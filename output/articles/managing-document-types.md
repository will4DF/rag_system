Managing Document Types is a critical part of setting up your document tracking in Element451

# Overview

Document Types in Element451 are essential for identifying and managing the various types of documents required throughout your instance.

[![](https://downloads.intercomcdn.com/i/o/1085642805/e4fa00c6b04e627f603cc9bd/Important+-+Orng.png?expires=1784333700&signature=cf0b7e1abfabb6d7c20195e882a22e7d32ddf66306a408c1aa793efa77eaf9d6&req=dSAvE896n4lfXPMW1HO4zVIc8qbzUaGVyv8aNlZ14utM0js7%2FfCM2FOh3a3J%0A4%2BVpBLitygbd7NGyABc%3D%0A)](https://downloads.intercomcdn.com/i/o/1085642805/e4fa00c6b04e627f603cc9bd/Important+-+Orng.png?expires=1784333700&signature=cf0b7e1abfabb6d7c20195e882a22e7d32ddf66306a408c1aa793efa77eaf9d6&req=dSAvE896n4lfXPMW1HO4zVIc8qbzUaGVyv8aNlZ14utM0js7%2FfCM2FOh3a3J%0A4%2BVpBLitygbd7NGyABc%3D%0A)

Documents cannot be viewed on a user’s profile without an associated document type. Document Types are also crucial for the Decisions module, and any document you want to display on an applicant’s document page must have a document type.

# Adding a New Document Type

You must create document types for each document you want to collect. Once a document type is created, it can be selected from the Type list when manually uploading documents.

To add a new document type:

1. Navigate to **Data + Automations** > **Documents** > **Document Types**.
2. Click the **blue plus sign** button in the bottom right corner to add a new type.  
   ​

   [![](https://downloads.intercomcdn.com/i/o/1085701697/cfcf7f86fbc54e7d3c330b6e/Screenshot+2024-06-18+at+10_13_12%E2%80%AFAM.png?expires=1784333700&signature=36b18ec9f9c85fc735f803382e8aa528d5050f85abb51b4c67d7f9a213e58ac1&req=dSAvE85%2BnIdWXvMW1HO4zRutvufL3teyLf1GLznsDOr8Wy302H%2FbDvbzbQxH%0Am3tM%0A)](https://downloads.intercomcdn.com/i/o/1085701697/cfcf7f86fbc54e7d3c330b6e/Screenshot+2024-06-18+at+10_13_12%E2%80%AFAM.png?expires=1784333700&signature=36b18ec9f9c85fc735f803382e8aa528d5050f85abb51b4c67d7f9a213e58ac1&req=dSAvE85%2BnIdWXvMW1HO4zRutvufL3teyLf1GLznsDOr8Wy302H%2FbDvbzbQxH%0Am3tM%0A)
3. Configure the settings for the new document type:

   * **General** tab: Name your document type and update the slug if desired
   * **Icon** tab: Select an icon for the document type

# Creating a Custom Field for a New Document Type

In this example, we've just created a new Document Type. Now, we want students to be able to upload documents of this new Type. To do that, we'll need to create a Custom Field where those documents will be mapped.

To create a custom field:

1. Navigate to **Data + Automations** > **[Field Management](https://help.element451.com/en/articles/9118615-field-management)**.
2. Select **Custom Fields** from the left-hand menu.
3. Click the **plus sign** button in the top right corner of the header.  
   ​

   [![](https://downloads.intercomcdn.com/i/o/1085759561/ff9847585e6cc8314c5306c7/Screenshot+2024-06-18+at+11_22_00%E2%80%AFAM.png?expires=1784333700&signature=8843b756ec565bb821ff13a2bbd5e50be51e0aa0a5cb7bad3d096f0881e65e21&req=dSAvE857lIRZWPMW1HO4zbghdLCd%2FKTl1v4vd2KnzPvLUSp2fBmrVVvhRtPM%0AKjFQ%0A)](https://downloads.intercomcdn.com/i/o/1085759561/ff9847585e6cc8314c5306c7/Screenshot+2024-06-18+at+11_22_00%E2%80%AFAM.png?expires=1784333700&signature=8843b756ec565bb821ff13a2bbd5e50be51e0aa0a5cb7bad3d096f0881e65e21&req=dSAvE857lIRZWPMW1HO4zbghdLCd%2FKTl1v4vd2KnzPvLUSp2fBmrVVvhRtPM%0AKjFQ%0A)
4. Choose the **type** of custom field. In this case, we'll use the "Upload" type.  
   ​

   [![](https://downloads.intercomcdn.com/i/o/1085760912/ea01ccbec57b903f3e451859/Screenshot+2024-06-18+at+11_24_53%E2%80%AFAM.png?expires=1784333700&signature=2000e4a7802c6ae880dfa74848091602ee0bf0bc5bbb36659885b366f2791d11&req=dSAvE854nYheW%2FMW1HO4zcxJWVgEnYruBIqb%2BotiA0iLrZmsznRTkdgRnlVI%0AXY%2Ft%0A)](https://downloads.intercomcdn.com/i/o/1085760912/ea01ccbec57b903f3e451859/Screenshot+2024-06-18+at+11_24_53%E2%80%AFAM.png?expires=1784333700&signature=2000e4a7802c6ae880dfa74848091602ee0bf0bc5bbb36659885b366f2791d11&req=dSAvE854nYheW%2FMW1HO4zcxJWVgEnYruBIqb%2BotiA0iLrZmsznRTkdgRnlVI%0AXY%2Ft%0A)
5. Configure the custom field settings within the General and Validation tabs. Our article on [Field Management](https://help.element451.com/en/articles/9118615-field-management) covers this in more depth.
6. Once the custom field has been created, you can add it anywhere in Element451 that you would like someone to upload that type of document.
