# Overview

Beyond basic complete or incomplete statuses, you can create custom statuses to reflect your specific workflow needs for both **internal** and **contact tasks**. While they share the same setup space, internal and contact tasks have **separate, independent status lists**.

These custom statuses align with three main status types—**To Do**, **In Progress**, and **Done**—offering greater flexibility for more complex setups. For example, you can add statuses like “On Hold” or “Pending Approval” under **In Progress** to better manage tasks as they progress through different stages, giving you full control over your task workflows.

# Default Status

When creating a new task, the Status is a required field. Admins can set a default status to pre-populate the status fields and streamline manual task creation.

In most cases, the Default Status should be set to a Status with a Status Type of To-Do.Use the drop-down field to change your Default Status.

# Adding a Custom Status

1. Ensure you are in the correct category in the left-hand menu—internal or contact.
2. Click the **+ Add New Status** ![](https://downloads.intercomcdn.com/i/o/911857802/4594f01ff6713fe754719fd5/Screenshot+2023-12-17+at+1.31.41%E2%80%AFPM.png?expires=1784430000&signature=6a02b43157964330fcec77d1cdfbf0939ec74a47372adca70e2e108b42fcb5a6&req=fSEmHsx5lYFdFb4X1HO4gfHI6x1SRnQtS3ivyPwJC9JGCAb8lrqsWujit7Lk%0A) buttonat the bottom of the Status list**.**
3. Replace "**Untitled**" at the top with a name for your Status.
4. Enable or disable your Status by using the toggle.
5. Select the status type with which you'd like to associate this status.
6. Click **Save**.

[![](https://downloads.intercomcdn.com/i/o/911858915/808d398e7f1fa7d013e4023a/Screenshot+2023-12-17+at+1.35.34%E2%80%AFPM.png?expires=1784333700&signature=15237aa733c345ea14f60d916eaf520bacf0ffa86edfd3893e4909e72831df6d&req=fSEmHsx2lIBaFb4f3HP0gPtml3cX%2BDUDTsZM8TKKI%2BHo%2BY0LCNSj0Ag1701x%0AdpUH91K2T5oVtsCs0A%3D%3D%0A)](https://downloads.intercomcdn.com/i/o/911858915/808d398e7f1fa7d013e4023a/Screenshot+2023-12-17+at+1.35.34%E2%80%AFPM.png?expires=1784333700&signature=15237aa733c345ea14f60d916eaf520bacf0ffa86edfd3893e4909e72831df6d&req=fSEmHsx2lIBaFb4f3HP0gPtml3cX%2BDUDTsZM8TKKI%2BHo%2BY0LCNSj0Ag1701x%0AdpUH91K2T5oVtsCs0A%3D%3D%0A)

# Editing + Deleting a Status

![](https://downloads.intercomcdn.com/i/o/h9r2yo9x/1205829409/f1ebecb8450ebafa3234ee291d46/Note.png?expires=1784430000&signature=c211f11499725d2f272ba50f545297ad1e945fd22d77938898f940a9645f1354&req=dSInE8F8lIVfUPMW3Hu4ge0HLrCBsEEpRdoIeNM8jzYyDb7cNzeqEFMYnFjm%0APg%3D%3D%0A) You must have at least one "to-do" and one "done" status enabled for Tasks to function.

1. Click the ![](https://downloads.intercomcdn.com/i/o/910888780/681abf51f74be074b2d65046/Screenshot+2023-12-15+at+1.24.20%E2%80%AFPM.png?expires=1784430000&signature=de48a4d82f92c22408b388dc8934e675adb0be75a1104ac7a23e9446361d21da&req=fSEnHsF2molfFb4X1HO4gdzeAjfHjg7DATYTYpihz0e%2FFf3t0gpZdrDmJbnK%0A)on the right of the row of the Status you wish to edit or delete.
2. Select **edit** or **delete**, depending on what you wish to do.
3. If deleting, you'll be prompted to confirm the action.

   * If the status is unused, you'll receive the following prompt:

     [![](https://downloads.intercomcdn.com/i/o/910917497/bd7229da72afbe3233bb2847/Screen+Shot+2023-01-10+at+3.18.46+PM.png?expires=1784333700&signature=ef433c8964ddbfccd8935ab70a894031c89814c04c5c1ff460febb771614a4c7&req=fSEnH8h5mYhYFb4f3HP0gGt%2FnM8BGeY7UsT1w6268PhHOsI3RQdNDIZp6S1b%0AVN8%3D%0A)](https://downloads.intercomcdn.com/i/o/910917497/bd7229da72afbe3233bb2847/Screen+Shot+2023-01-10+at+3.18.46+PM.png?expires=1784333700&signature=ef433c8964ddbfccd8935ab70a894031c89814c04c5c1ff460febb771614a4c7&req=fSEnH8h5mYhYFb4f3HP0gGt%2FnM8BGeY7UsT1w6268PhHOsI3RQdNDIZp6S1b%0AVN8%3D%0A)
   * If the Status is currently associated with one or more tasks, you'll receive a prompt indicating the number of tasks with that Status and asking you to set those tasks to a new Status.

     [![](https://downloads.intercomcdn.com/i/o/910918195/4600701a8cecdae2b1ace93b/Screen+Shot+2023-01-10+at+3.20.13+PM.png?expires=1784333700&signature=c3e4b8fb8709d26263d9ceb550cd9374d0f84e646fadc797765060cbf0324644&req=fSEnH8h2nIhaFb4f3HP0gDurrM%2Fn3pZbNwbv0Ulb05M8WMM5nLAVwdS%2FRXPz%0AZrU%3D%0A)](https://downloads.intercomcdn.com/i/o/910918195/4600701a8cecdae2b1ace93b/Screen+Shot+2023-01-10+at+3.20.13+PM.png?expires=1784333700&signature=c3e4b8fb8709d26263d9ceb550cd9374d0f84e646fadc797765060cbf0324644&req=fSEnH8h2nIhaFb4f3HP0gDurrM%2Fn3pZbNwbv0Ulb05M8WMM5nLAVwdS%2FRXPz%0AZrU%3D%0A)
4. If editing, the Status edit side sheet will open. Make any changes and when finished, click **Save** in the top right corner.
