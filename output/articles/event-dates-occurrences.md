Learn about adding occurrences to events, single versus repeatable dates, setting attendance limits, date exclusions, and more.

# Overview

This article covers adding date(s) and times or occurrences after an event has been created. When adding dates to your events, you can add **single** or repeatable dates, and we'll cover each below. Additionally, you can set **date** **exclusions** for things like campus closures to block off a date or date range so repeatable events are not published on those dates.

# Single Date vs. Repeatable Dates

## Single Date

The event will happen only once or more than once but at different times that don't follow a weekly, monthly, or yearly pattern. With this option, you'll add each occurrence manually and can associate multiple dates with a single event. Single Date is ideal for events like orientation, where each session occurs at different times.

## Repeatable Dates

The event will happen more than once on a consistent weekly, monthly, or yearly basis at the same time for the same duration. The Repeatable option simplifies scheduling by automatically duplicating one event date across your chosen period, making it perfect for regularly scheduled events such as weekly campus tours.

# Adding an Occurrence

You can add as many dates as you'd like by following the steps below:

1. Navigate to **Engagement** > **Events** > **All** **Events**.
2. Click on your event's name or the **pencil** icon to open the editor.
3. Click the **Add** **a Date** button at the bottom of the page.  
   ​

   [![](https://downloads.intercomcdn.com/i/o/999875851/9ca0bed00d48c2c47209c0b9/Events+-+Add+Date.png?expires=1784333700&signature=cd762e8aecc706eefef2c27d577aec351c440ed86558427ba442ad47c6d5aa36&req=fSkuHs57lYReFb4f3HP0gF%2F%2B8Y3RDtIzQZifg8X%2BPf2vmAfHnkwEHAWu02Wx%0AtwM%3D%0A)](https://downloads.intercomcdn.com/i/o/999875851/9ca0bed00d48c2c47209c0b9/Events+-+Add+Date.png?expires=1784333700&signature=cd762e8aecc706eefef2c27d577aec351c440ed86558427ba442ad47c6d5aa36&req=fSkuHs57lYReFb4f3HP0gF%2F%2B8Y3RDtIzQZifg8X%2BPf2vmAfHnkwEHAWu02Wx%0AtwM%3D%0A)
4. Select **Single Date** or **Repeatable Date.**
5. Configure the event [occurrence details and configuration](#h_15ec643f1c) outlined in the next section.
6. Once you have configured the details based on your date type, click **Add** in the top right corner.
7. You will now see the date in the list of Event Dates.
8. If you need to add occurrences, repeat the above steps.

## Occurrence Details + Configuration

|  |  |
| --- | --- |
| **Period of Time (Repeatable Dates only)** | **Weekly**: Events that occur every week. This setting allows you to schedule your event for one or more specific days within the week. It's ideal for events that must be repeated on certain days every week.    **Monthly**: Events that don't occur every week but more sporadically, such as bi-weekly or on specific weeks of the month. You can specify both the week(s) of the month (first, second, third, fourth, fifth) and the day(s) of the week (Monday through Friday) on which the event will take place. This option suits events with a regular monthly pattern but less frequent than weekly events.    **Yearly**: Events that occur annually, allowing you to select the month(s), week(s) of the month, and day(s) of the week the event will happen. This configuration is perfect for events tied to specific annual dates or periods, like annual festivals or yearly academic events. |
| **Start Date** | Select the date the event will begin by clicking the calendar or type your date in "m/d/yyyy" format. |
| **End Date** | If your event occurs on only one day, set this to the same date as the Start Date. If the event spans multiple days (orientation, for example), enter an End Date. |
| **Full-Day Event** | If your event has no start and end time, click this slider to the "Yes" position. If not, move on to the next item. |
| **Start Time/End Time** | If you did not select 'full-day event,' the option to choose your event's start and end times will appear. You can select time in 15-minute increments. |

### Number of Attendees

The Number of Attendees setting caps the **total headcount** for the occurrence — the registrant **plus** any guests they bring. Once this number is reached, the registration form automatically closes. If set, this will override the default limit specified in the Signups tab.

[![](https://downloads.intercomcdn.com/i/o/999821931/d6ff95f561c0939dddee821e/Note-Orng.png?expires=1784333700&signature=3844c71ca5477b4d62d63b97c8c1c8b91972a95bf8c780114f89d3f62180c419&req=fSkuHst%2FlIJeFb4f3HP0gNe%2BEYBDiSA6Mnn90H%2B9lzir5KBBUTwNng%2BV9ZY4%0AcXHGFkfmErdIPTVtSA%3D%3D%0A)](https://downloads.intercomcdn.com/i/o/999821931/d6ff95f561c0939dddee821e/Note-Orng.png?expires=1784333700&signature=3844c71ca5477b4d62d63b97c8c1c8b91972a95bf8c780114f89d3f62180c419&req=fSkuHst%2FlIJeFb4f3HP0gNe%2BEYBDiSA6Mnn90H%2B9lzir5KBBUTwNng%2BV9ZY4%0AcXHGFkfmErdIPTVtSA%3D%3D%0A)

This is a per-occurrence limit. For example, if you have an event that occurs once per week and its *Number of Attendees* is set to 15, **each** **weekly** **occurrence** will accept 15 registrations.

Additionally, the event landing page has an "available spots" feature that lets attendees know how many spots are available. The number of available spots is displayed on the event landing page and automatically updates as attendees register. This cannot be disabled at this time. If an attendee limit is not set, the landing page only displays "*Available Spots*."

[![](https://downloads.intercomcdn.com/i/o/999868010/2a404d5c8856581471e4c8b3/Events+-+Avail+Spots.png?expires=1784333700&signature=9dc8e13c1a79ce495a3f899479f58c8f44f4a3b5221f8c4592ca18540fb8233e&req=fSkuHs92nYBfFb4f3HP0gAwLWdXwpUqBP5uMtbmSxQ4xigeE1s7M3oymO8IY%0AiAkLqGHt9By2Yn7hFw%3D%3D%0A)](https://downloads.intercomcdn.com/i/o/999868010/2a404d5c8856581471e4c8b3/Events+-+Avail+Spots.png?expires=1784333700&signature=9dc8e13c1a79ce495a3f899479f58c8f44f4a3b5221f8c4592ca18540fb8233e&req=fSkuHs92nYBfFb4f3HP0gAwLWdXwpUqBP5uMtbmSxQ4xigeE1s7M3oymO8IY%0AiAkLqGHt9By2Yn7hFw%3D%3D%0A)

* If you want the event registration form to close automatically once a certain number of attendees have registered for this specific event date/time, you can input a maximum number of attendees here. If you are allowing attendees to add guests, be sure that number is included in your count.  
  ​
* If you want to close event registration yourself or allow unlimited signups, leave this field blank.

#### Events without Registration

If you add an attendee limit, it will display on the event landing page, letting attendees know how many spots are available. Since signups are disabled, that number will not update unless you manually change it.

### Max Registrants

Use the Max Registrants setting to cap how many **registrants** (people who fill out the signup form) can sign up for the occurrence, independently from the total attendee count. This is useful when one part of your event has a hard cap on prospective students, but the venue can accommodate more total attendees once family members and guests are factored in.

**Example.** Your spring Open House includes a hands-on engineering lab demo. The lab has 25 workstations, but the rest of the event — welcome session, campus tour, lunch — can comfortably host 100 people. You want prospective students to bring family with them.

Set the limits as follows:

* **Max Registrants:** 25 (one per lab workstation)
* **Number of Attendees:** 100 (total venue capacity)
* **Number of Guests:** 3 (family members per student)

Registration closes as soon as **either** the Max Registrants cap **or** the Number of Attendees cap is reached. So if 25 students register and each brings just one family member (50 attendees total), the form still closes — the 25-registrant cap is hit even though the venue has plenty of room. Without Max Registrants, you'd have to set Number of Attendees = 25 (denying guests entirely) or risk overflowing the lab.

Leaving Max Registrants blank preserves existing behavior — only Number of Attendees applies. Like the other limits, if Max Registrants is set on an occurrence, it overrides the default in the Signups tab.

### Number of Guests

When registering for an event, you can allow attendees to add a guest count to their registration. This setting facilitates that feature.

## How does it work?

In the 'How Many People Are Attending' field on your event sign-up form, attendees will see options up to your set guest limit plus one—that extra one is for the attendees themselves. For instance, choose a limit of 2 guests, and the options will be 1, 2, or 3. This lets your attendees indicate if they plan to attend alone or bring guests within the limits you've set.

## To allow guests to be added:

* Input a value for the 'Number of Guests' limit.
* Note: This will override your default limit specified in the Signups tab.

## To disallow guests from being added:

* Leave the 'Number of Guests' field blank.
* When this is the chosen route, the 'How Many People Are Attending' field on your event sign-up form will be hidden since only the attendee is registering.

# Repeatable Events - Date Exclusions

You can add a date exclusion if you want to exclude specific dates from your repeatable events (e.g., campus closures).

1. Navigate to **Engagement** > **Events** > **All** **Events**.
2. Click on your event's name or the **pencil** icon to open the editor.
3. Click on Event Date(s) in the left-hand menu from the Event Overview tab.
4. Click on the **Exclusions** tab.
5. Click **Add** **Exclusion**.
6. Select the type: **single** **date** or **date** **range**
7. Use the date picker to select the date(s) you wish to exclude.
