# Overview

The Bolt Discovery dashboard analyzes the performance of all Bolt Discovery metrics. Explore performance metrics by date, Knowledge Hub articles, and topics.

## Accessing the Dashboard

The Bolt Discovery dashboard can be found via the Insights sub-menu. The Insights module can be accessed from the Data + Automations dropdown in the top navigation.

---

# Dashboard Features

The Bolt Discovery dashboard displays search data over time and a wide variety of performance measurements.

## Global Controls

The Bolt Discovery dashboard can be filtered and controlled in several ways. Find the global controls at the top of each tab. These global controls affect each tab. Filters applied on one tab will carry over to the others.

Global controls feature filters for **dates, comparison (previous period) dates, Knowledge Hub type, Knowledge Hub title, Knowledge Hub gap, topic, and a StudentHub toggle to see how Bolt Discovery is used specifically on that feature**. Select one or many from most control categories.

# Tabs

Data on the Bolt Discovery dashboard is organized by date as well as various dimensions selected in the controls menu.

## Overview Tab

**Visualizations**

* *Highlights*

  + Period-over-period performance of threads.
  + Period-over-period performance of queries.
  + Period-over-period performance of Knowledge Hub.
  + Table of threads, queries, and Knowledge Hub articles referenced by date, article, and topic.

* *Knowledge Hub*

  + Table of specific queries unable to be answered.
  + Table of keywords without an adequate response.

## Query Log Tab

**Visualizations**

* *Table*

  + Breakdown of every single question and answer in Bolt Discovery as well as a link to the thread.

# Metric Glossary

|  |  |
| --- | --- |
| **Metric** | **Definition** |
| Threads | A group of a series of questions asked by the same user during the same search session. |
| Queries | Specific questions asked during a thread. |
| Articles Referenced | How many times a specific Knowledge Hub item is returned in response to a query. |
| Queries per Thread | Number of queries / Number of threads |
| Minutes per Thread | (Time of thread update - Time the thread started) / Number of threads |

# **Troubleshooting & FAQ**

* ## Why is there no data?

  There are a variety of reasons an Insights report is blank. Try the following quick fixes:  
  ​

  + **Reset the report.** Visualizations may be filtering the report. Check the date controls. If the date is too far in the past, it may pre-date your activity in Element451.
  + **Check** what fields are being used.
  + If data is still missing, there may be issues with your data in Element. Check out [this guide](https://help.element451.com/en/articles/4404458-a-guide-for-data-clean-up) for **data cleanup.**
* ## **How often does the Bolt Discovery dashboard update?**

  The Conversations dashboard currently refreshes once a day at 12:00 am Eastern.
