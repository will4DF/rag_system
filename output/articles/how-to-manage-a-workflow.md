# Editing a Workflow

**Before editing a Workflow, here are a few important notes:**

* **Make Workflows Inactive Before Making Changes:** Ensuring that a workflow is inactive before editing minimizes the risk of interruptions to contact records in the processing queue. When changes are made to an active workflow, such as removing or modifying steps, there is an increased risk of workflow interruptions. While contacts may still process without issues in certain scenarios, the safest approach is to temporarily deactivate the workflow before implementing any changes.
* If a Contact is already in a Workflow, only changes to steps they haven’t reached will affect them.
* Enrolled Segments cannot be removed from a Workflow. You will need to set the Workflow to inactive, duplicate it from the Workflows page, and then select the new Workflow to proceed.

**To edit a Workflow, follow these steps:**

1. Navigate to ***Data + Automations > Workflows > All Workflows***
2. Locate and **click on the name of the Workflow** you want to edit

## Starting and Stopping Workflows

**Note**: If you stop a Workflow, the already enrolled contacts will stop at the step they have reached. They will not be affected by any other actions as per the Workflow. Furthermore, no new Contacts will be added to the Workflow until it is restarted.

Navigate to the drop-down menu near the name of the Workflow that says Active or Inactive, depending on its current state. Set it to ***Active*** if you want it to run or ***Inactive*** if you want it to stop running.

[![](https://downloads.intercomcdn.com/i/o/687774618/30530f7236fdb42ec1c9c16b/active.gif?expires=1784333700&signature=fe4157d345fb0fdf55a6c710f546556ce81531056a1e1eb9a887c98ba60c375e&req=ciggEc56m4BXFb4f3HP0gGjeES5vcoN7jav6jHe0HQkSW7dfbgOyy%2FvbL6JG%0AfICQmQ%2FynhD%2Fy7qKfg%3D%3D%0A)](https://downloads.intercomcdn.com/i/o/687774618/30530f7236fdb42ec1c9c16b/active.gif?expires=1784333700&signature=fe4157d345fb0fdf55a6c710f546556ce81531056a1e1eb9a887c98ba60c375e&req=ciggEc56m4BXFb4f3HP0gGjeES5vcoN7jav6jHe0HQkSW7dfbgOyy%2FvbL6JG%0AfICQmQ%2FynhD%2Fy7qKfg%3D%3D%0A)

# Removing a Contact from a Workflow

Removing a Contact from a Workflow will prevent them from advancing to other steps. This action cannot be undone once you confirm the removal, but they can reenter the Workflow in the future.

To remove a Contact from a Workflow:

1. **Open** the Workflow to edit it.
2. Click the **People** tab at the top.
3. Click the more icon (three vertical dots) at the end of the Contact's row.
4. Select **Remove Workflow**.

# Ending the Workflow for a Contact

They will not move forward in the Workflow. This action cannot be undone.

To end the Workflow for a Contact:

1. **Open** the Workflow to edit it.
2. Click the **People** tab at the top.
3. Click the more icon (three vertical dots) at the end of the Contact's row.
4. Select **End Workflow**.

# Troubleshooting Stuck Contacts in Workflows

If you encounter a situation where a contact record gets stuck in a workflow after making changes, try the following solution:

* **Manually Remove and Re-Add the Record:** Identify the record (contact) stuck in the workflow. Remove it from the current workflow and then manually re-add it. This action allows the contact to re-enter the workflow under the updated configuration, ensuring correct processing moving forward.
