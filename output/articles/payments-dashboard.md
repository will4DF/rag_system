# Overview

The Payments dashboard shows trends and aggregate data related to payments made via the Element451 platform.

## Accessing the Dashboard

The Payment dashboard can be found via the Insights sub-menu. The Insights module can be accessed from the Data + Automations dropdown in the top navigation.

---

***Global Controls***

* Payment type: Select between deposits and application fees to see the variety of metrics for a particular type of payment.
* Application Name: Filter your data for one or more applications.
* To and From Date: Sets the date range filter for the dashboard.
* Previous Period To and From Date: Sets the date range filter for the Previous Period data for comparison.
* Segments: See your email/sms performance by calculated segment.
* Demographics: Filter your data by state, term, major, or student type.

***Segment Filters***

The Payments report can only be filtered by certain dimensions by default. The segment filter is a great way to filter the report by dimensions that matter to you. Create a segment in the People module, and set it as a calculated segment.

Please allow 24 hours for new calculated segments to appear and filter correctly in Insights.

More on using [segments and Insights](https://help.element451.com/en/articles/6798155-using-segments-in-insights) together.

# **Metric Glossary**

All metrics are calculated based on the specific datetime of a particular payment action.

|  |  |
| --- | --- |
| **Metric** | **Definition** |
| Payments Received | The number of payment actions taken given the selected parameters. |
| Payment Amount | The dollar amount for payment actions taken given the selected parameters. |
| Discount Codes Entered | The number of payment actions where a discount code was used. |
| Discount Amount | The dollar amount of discounts applied where a discount code was used. |

# **Troubleshooting & FAQ**

* ### Why is there no data?

  There are a variety of reasons an Insights report is blank. Try the following quick fixes:  
  ​

  + **Reset the report.** Visualizations may be filtering the report. Check the date controls. If the date is too far in the past, it may pre-date your activity in Element451.
  + **Check** what fields are being used.
  + If data is still missing, there may be issues with your data in Element. Check out [this guide](https://help.element451.com/en/articles/4404458-a-guide-for-data-clean-up) for **data cleanup.**
* ### **How often does the Payments dashboard update?**

  The Campaigns dashboard currently refreshes once a day at 12:00 am Eastern.
