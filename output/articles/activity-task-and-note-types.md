Create and use custom types to define activities, tasks and notes.

# Overview

**Types** are common definitions for your *activities*, *tasks*, and *notes* within Element451. Creating custom types enables your team members to categorize what they track during your recruitment process.

## Accessing Activity, Task, and Note Types

1. Click on your profile picture/avatar in the top right corner of the orange navigation menu.
2. Navigate to **Settings** > **Activity, Tasks, and Note Types.**

# Creating Types

1. Click on your profile picture/avatar in the top right corner of the orange navigation menu.
2. Navigate to **Settings** > **Activity, Tasks, and Note Types**.
3. Click the **blue** **plus** **button** ![](https://downloads.intercomcdn.com/i/o/1046679619/98558d2890a9430d1af1f309/%2B+Plus+Button+Transparent.png?expires=1784430000&signature=37b4e98c79036a5faf399855e6683e1608dd113374144b4dd85b9f93ad2fe7aa&req=dSAjEM95lIdeUPMW3Hu4gRRnWR80l4En0ibLubI%2BJhTApKj9H%2B%2BCo%2FH4HZTH%0A7A%3D%3D%0A) in the lower left corner.
4. Create a name for the type and choose an icon to represent it.

# Editing + Deleting Types

1. Click on your profile picture/avatar in the top right corner of the orange navigation menu.
2. Navigate to **Settings** > **Activity, Tasks, and Note Types**.
3. Locate the Type you wish to edit or delete.

   * Click the **pencil** ![](https://downloads.intercomcdn.com/i/o/1046681767/28170f09221fd7852ec65622/Pencil+Icon.png?expires=1784430000&signature=3ed05557cd41629347c92a01f72ad96c87f5a56131cded5c6f9ff7dbd1aaaeff&req=dSAjEM92nIZZXvMW3Hu4gTuFbEInu7rJjY%2BSXiM5KQdCPOyreaJ297y7foMx%0AxA%3D%3D%0A) to edit.

# Using Types

All types are **shared** between Activities, Tasks, and Notes. New types you create will be available when creating these items.

## Activity Types

Custom activity types can be used when creating a new activity on the student record. Learn more about adding and viewing custom activities [here](https://help.element451.com/en/articles/3097376-activity-feed-adding-custom-activities).

**Segmenting by Activity Type:** When creating Segments, you can use the *Custom Activity* filter. Learn more about filters [here](https://help.element451.com/en/articles/1476084-filters-overview).

## Task Types

Custom task types can be used when creating new tasks. Learn more about creating and managing tasks [here](https://help.element451.com/en/articles/3065709-getting-started-with-tasks).

**Segmenting by Task Type:** When creating Segments, you can use the *Task > Type* filter. Learn more about filters [here](https://help.element451.com/en/articles/1476084-filters-overview).

## Note Types

Custom note types can be used when creating notes from the Notes profile card on the student record. Learn more about profile cards [here](https://help.element451.com/en/articles/1475735-the-person-profile#h_8456eb5949).

**Segmenting by Note Type:** When creating Segments, you can use the *Notes > Type* filter. Learn more about filters [here](https://help.element451.com/en/articles/1476084-filters-overview).
